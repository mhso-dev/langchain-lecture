## 확인 필요 항목

교육 검수와 코드 실행을 통과했다. 브라우저의 실제 모바일·데스크톱 조작 확인은 보류했다. 로컬 Chrome 실행은 프로세스 권한으로, 앱 내 브라우저의 로컬 파일 열기는 프로토콜 정책으로 막혔다. 전체 전달 판정은 in_review다. Windows/WSL에서의 실행, 학생 팀 계정·저장소 권한, 수강생의 실습 소요 시간은 현장 확인 대상이다. 후속 단원용 모범 응답은 사람이 원문과 대조해 작성했으며 모델 호출·LangSmith 실행 기록으로 채점하지 않았다.
