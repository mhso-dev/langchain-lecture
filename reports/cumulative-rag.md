## 실제 입력과 결과

14장은 앞 장에 새로 저장한 “강의실은 홍실 9층입니다”를 프롬프트에서 읽었다. 15장 PDF 추출에서는 A형 1.0판·1.1판 2쪽에 각각 30분·45분이 있었다. 16장 기본 분할에서 쪽과 청크는 각각 6개였고, 95자로 나눠도 파일명·쪽수 쌍은 보존됐다. 독립 검수자는 별도의 ‘솔방 499호’ 입력으로 14~16장을 다시 풀었다.

17~24장의 장간 검사는 새 커널에서 현재 파일을 이어 읽고 Chroma에 보관된 실측 문서 벡터를 사용했다. 6개의 저장 문서가 현재 PDF 원문과 같은지도 대조했다. 질문 임베딩은 통제된 벡터, 채팅·재정렬은 검사용 응답을 넣었다. 실제 LCEL 메시지 구성과 파싱, 컬렉션 재열기, 판본 필터, 빈 후보 보류, 페이지 단위 채점, 인계 JSON 저장을 확인했다. 이 과정에서 기록한 순위와 생성 답변은 새로운 라이브 품질 측정치가 아니다.

Streamlit AppTest에서 학생 앱의 제목을 바꾸고 별도 질문·대화 파일을 넣었다. 지난 대화를 열면 두 말풍선이 표시되고 호출 수는 0이었다. D04를 보내면 질문·답 말풍선이 한 개씩 생겼고, 체크박스 변경으로 추가 호출이 없었다. 새 대화로 돌아가면 이력과 전송 횟수가 0이었다. 독립 검수자도 자기 제목과 대화 파일로 23·24장 생성 셀과 복원 버튼을 재확인했다.

## 교육 검수와 수정

과거 강사용 자료의 RecursiveCharacterTextSplitter 예제에서 같은 문자열의 분할 경계를 비교한 절, 12장의 셀·접힌 풀이, 14장의 호출 설명, 33장의 상태 변화를 읽고 본문에 적용했다. 기존 시작 예제와 과제를 유지하면서 실제 파일을 여는 응용 절을 추가했다. 독립 검수자가 지적한 15장의 질문 설명을 코드와 맞췄다. 13장 앱이 참조하는 chat-sample.json도 각 앱에 복사하도록 수정했다. 18장은 색인 폴더가 보존된 경우만 질문 벡터를 새로 요청한다고 명시했다. 22장의 순위는 18장에서 재실행한 결과를 읽는다. 23·24장 UI의 횟수는 ‘전송한 질문’으로 표시한다. 검수자가 수정된 네 범위와 로컬 풀이를 다시 확인했다.

## 한국어 최종 검수와 확인 필요 항목

산문 S1 검수에서 중복된 예고 문장과 ‘어제’ 같은 수업 시점 표현을 줄였다. PDF 원문·판본, 검색 입력과 채점 키, 파일명이 보존됐는지 개정 절과 최종본을 다시 읽고 대조했다. 한국어 판정은 corrected다. 구조 검사에서 변경률 1.7%와 장 번호 13·13·23의 반복 삭제가 경고로 남았다. 해당 대상 장은 여전히 명시돼 있고, 순서·시수·파일 경로도 원문과 일치한다. 공개 범위를 알 수 없어 외부 맞춤법 서비스 전송은 생략했다.

OpenAI 실제 호출은 승인을 받은 키를 해당 프로세스에만 로드해 임베딩 한 건을 시도했으나 연결이 차단됐다. 14·17~24장 신규 전체 라이브 실행, LangSmith 계정 화면 및 학생 Windows/WSL 실행은 보류다. 이 파일의 코드 판정과 웹 빌드·배포 판정은 별도로 기록한다.
