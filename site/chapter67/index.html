응답의 인용과 숫자를 각각 채점해 API 시험 요청 만들기

같은 문서 번호를 인용해도 대출 일수는 틀릴 수 있습니다. 66장의 실제 응답을 서비스 원문에서 얻은 기준과 대조하고 다음 장 FastAPI에서 재사용할 요청을 남기세요.

import re
record = previous["record"]
expected_days = re.search(r"[0-9]+일", record["text"]).group()
expected = {"status": "answered", "source_id": record["id"], "answer_contains": expected_days}
def score(reply, expected):
    return {"status": reply["status"] == expected["status"],
            "citation": expected["source_id"] in reply["sources"],
            "duration": expected["answer_contains"] in re.findall(r"[0-9]+일", reply["answer"])}
checks = score(previous["observed"], expected)
print(checks)

실행 결과

{'status': True, 'citation': True, 'duration': True}

citation은 출처 목록을 읽습니다. duration은 답에서 일수를 전부 추출한 뒤 값 전체가 같은지 확인하므로 14일과 114일을 구분합니다. 기준 일수는 답변에서 복사하지 않고 54장의 원문에서 다시 읽습니다.
