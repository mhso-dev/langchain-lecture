02

csv.DictReader와 문자열 필드

CSV의 열을 읽으면 숫자처럼 보이는 값도 문자열일 수 있습니다. 변환할 열과 누락으로 처리할 값을 먼저 정하면 정제 결과를 다시 확인할 수 있습니다.

이 CSV에서는 쉼표가 한 줄 안의 칸을 나누고 줄바꿈이 행을 나눕니다. 노트북에 넣은 여섯 줄은 예제 records.csv와 같습니다. StringIO로 파일처럼 열어 보므로 경로를 설정할 필요가 없습니다.

빈 minutes를 발견하자마자 0으로 저장하면 나중에 ‘0분 공부했다’와 ‘시간을 입력하지 않았다’를 구별할 수 없습니다. 이 예에서는 같은 ID로 20분을 적은 행도 뒤에 있습니다. 중복 제거를 먼저 하면 첫 번째 2번 행을 보존하는 방식에서는 유효한 20분 기록을 잃습니다.

CSV·JSON 직렬화와 역직렬화

CSV는 쉼표 같은 구분자로 열을 나누는 표 형식입니다. 값 안에도 쉼표가 있을 수 있어 문자열을 split(",")으로 자르지 않고 csv 모듈을 사용합니다. DictReader는 첫 행을 키로 삼아 각 행을 딕셔너리로 읽습니다. 여기서 분 값 "30"도 문자열입니다.

셀 01의 StringIO(csv_text)는 문자열을 파일처럼 한 줄씩 읽게 합니다. DictReader의 첫 행은 열 이름이어서 데이터 행 수에 포함되지 않습니다. rows에는 여섯 건이 들어 있습니다.

JSON은 표 외에도 중첩 목록·객체를 담을 수 있습니다. 이번에는 CSV 행 목록을 JSON으로 바꾸고 다시 읽어 값이 같은지 확인합니다. json.dumps와 loads는 문자열을 처리하고, 실제 파일 읽기·쓰기는 Path 메서드가 맡습니다.

유효성 검사와 중복 제거 순서

같은 id의 내용이 다르면 어느 것을 남길지 업무 규칙이 필요합니다. 여기서는 유효한 행 중 첫 행을 남긴다는 규칙을 명시했습니다. 모든 실제 데이터에 적용할 정답은 아닙니다.

drop_duplicates는 subset에 적은 열을 비교합니다. keep="first"는 현재 순서에서 첫 행을 남깁니다. 중복 제거를 먼저 하면 누락 시간의 id=2가 남고 유효한 20분 기록을 잃을 수 있습니다.

과제 04에서 by_id의 키는 원래 CSV의 문자열 ID입니다. 유효한 행을 순서대로 읽어 첫 번째 행을 저장하고, 같은 키를 다시 만나면 건너뜁니다. 이 순서를 바꾸면 비어 있던 ID 2의 첫 행 때문에 뒤의 20분까지 빠질 수 있습니다.

04

pandas의 결측값 판별

표 전체를 다룰 때는 Pandas의 DataFrame을 씁니다. 수업용 커널에 pandas가 있으면 아래 셀이 실제 열을 선택합니다. 설치되지 않은 환경에서도 앞의 CSV 실습은 그대로 동작합니다.

셀 05 · isna()로 결측값 검사

문자열로 읽은 뒤 숫자로 바꿀 수 없는 값을 결측값으로 표시합니다.

실행 결과

[False, True, False, False, False, False]

여섯 값 중 둘째가 True인 것은 시간 문자열을 숫자로 바꾸지 못했다는 뜻입니다. 제목만 비어 있는 넷째 행은 시간 15를 읽을 수 있어 False입니다. 제목과 시간이 모두 유효한 행을 고르는 일은 셀 03의 clean_row가 맡습니다.

pandas 행·열 선택

DataFrame은 행과 열로 구성한 표입니다. frame["id"]는 한 열인 Series를 선택하고, frame[["id", "minutes"]]는 여러 열을 가진 표를 선택합니다. frame.shape는 (행 수, 열 수)입니다.

read_csv에서 dtype=str로 읽어 id의 앞자리 0 같은 표시를 보존합니다. keep_default_na=False는 빈 칸과 NA 같은 글자를 처음에는 문자열 그대로 읽게 합니다. 누락을 어떻게 판정할지는 다음 단계에서 직접 정합니다.

frame["id"] == "2"는 각 행마다 참·거짓을 계산합니다. loc[행 조건, 열 목록]은 조건을 만족한 행과 지정한 열을 고릅니다. to_dict(orient="records")는 표를 행별 딕셔너리 목록으로 바꿉니다.

05

UTF-8 JSON 파일 쓰기와 읽기

메모리 안의 사전은 커널을 닫으면 사라집니다. 임시 폴더에 실제 파일을 저장하고 같은 인코딩으로 다시 열어 첫 유효 행의 값이 남았는지 확인합니다.

작업 디렉터리와 파일 경로

Path는 경로를 다루는 객체입니다. / 연산으로 폴더·파일 이름을 연결하고 resolve()는 절대 경로로 정리하며 parent는 부모 폴더를 뜻합니다. mkdir(exist_ok=True)는 폴더가 이미 있어도 오류를 내지 않습니다.

셀 06은 첫 유효 행을 임시 폴더의 record.json에 UTF-8로 씁니다. read_text()가 복원하는 것은 JSON 문자열입니다. minutes를 다시 숫자로 읽으려면 json.loads()까지 실행해야 합니다.
