# 공지를 읽고 빠진 사실 찾기

딕셔너리를 아직 써 보지 않았다면 [공지의 날짜와 장소를 꺼내는 노트북](notice-fields.ipynb)을 먼저 풀어 보세요.

원문은 [동아리 공지](../sources/club-notices.md)에서 가져온다. 노트북에는 내가 보낸 글과 받은 답을 각각 남긴다. 답안은 [대조 예시](../answers/club-and-loan.md)에서 확인할 수 있다.

| 수업 | 해 볼 일 | 확인할 것 |
| --- | --- | --- |
| 8일 | C1을 한 문장으로 요약해 달라고 요청한다. 같은 지시로 C2를 새로 보낸다. | 답에 날짜와 장소가 남았는가? 첫 번째 답의 장소는 C1과, 두 번째 답의 장소는 C2와 각각 일치하는가? |
| 9일 | C1을 다시 사용한다. “신입 회원에게 필요한 행동을 한 문장으로 알려 줘”에서 독자만 “진행자”로 바꿔 보낸다. | 두 사람이 챙길 일이 어떻게 다른가? 답에서 해당 구절에 밑줄을 긋는다. |
| 10일 | C1을 읽고 ‘모임 일시’와 ‘모임 장소’ 두 칸을 채워 예시 답을 만든다. 그 예시와 C3을 보내 같은 두 항목을 뽑아 달라고 한다. | C3에 장소가 있는가? 장소를 짐작했다면 예시나 지시를 고친다. C5를 처음 보는 공지로 시험한다. |
| 11일 | 같은 대화에 C4의 세 발화를 차례로 입력한다. 새 대화를 열어 세 번째 발화만 보낸다. | 실제로 모델에 보낸 이전 메시지와 각 답을 나란히 놓는다. 새 대화의 답에 앞선 모임 정보가 들어 있다면 그 출처를 실제 요청에서 찾아본다. |
| 12일 | 챗봇에서 C1 요약을 요청하고 이어서 “진행자는 몇 시까지 가야 하나요?”라고 묻는다. 화면 선택 항목만 한 번 바꾼다. | 메시지 두 쌍을 센다. 선택 항목을 바꾼 뒤 사용자 메시지와 모델 호출 횟수가 그대로인지 확인한다. |
| 13일 | 짝이 C5를 보내면 먼저 두 문장, 이어서 한 문장으로 안내하게 한다. 대화를 초기화한 뒤 마지막 요청만 다시 보낸다. | 한 문장으로 줄여도 제출 마감이 정확한가? 대화를 비우면 이전 공지까지 사라지는가? |
