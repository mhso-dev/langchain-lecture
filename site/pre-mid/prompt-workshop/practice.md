# 공지 편집자의 프롬프트 실험 기록

원문 C1·C2·C3·C5는 노트북에 들어 있습니다. 모델에 보낸 문장과 실제로 받은 답을 기록하세요. 답의 문장이 모범 예시와 달라도 원문의 사실과 맡은 일을 제대로 전달했다면 그 근거를 쓰면 됩니다.

## 신입 회원에게 정확한 장소 안내하기

처음 오는 회원이 공지 한 줄만 보고 찾아갈 수 있게 안내합니다. 먼저 C1으로 모델을 호출하고 날짜·시간·호수를 직접 적으세요. 다음에는 같은 지시문으로 C2를 보냅니다. 지시까지 바꾸면 장소 변경에 관한 두 결과를 비교하기 어렵습니다.

| 직접 기록할 값 | C1을 보낸 첫 호출 | C2를 보낸 두 번째 호출 |
|---|---|---|
| 사용한 지시문 | | |
| 실제 답 | | |
| 일시와 장소를 확인한 원문 구절 | | |
| 덧붙였거나 빠뜨린 안내 | | |

점검할 때는 C1이 201호, C2가 305호인지 봅니다. 두 원문의 모임 일시는 같습니다. 셀을 실행하지 않고 읽기만 했다면 실제 답은 빈칸으로 둡니다.

## 회원용 문자와 진행자용 문자 만들기

C1에서 독자만 바꿔 두 문자를 작성하세요. 회원 문자를 받은 사람이 가져올 물건, 진행자 문자를 받은 사람이 도착할 시각과 준비할 물건을 적습니다. 이제 하나를 골라 어투·길이·포함할 행동 가운데 조건 하나를 수정하세요.

| 기록 | 내 문장 |
|---|---|
| 최초 지시와 실제 답 | |
| 잘 전달되지 않은 행동과 근거 | |
| 변경한 지시 한 구절 | |
| 바뀐 답에서 그 조건을 확인할 문장 | |
| 다른 공지로 다시 시험할 점 | |

진행자는 오후 3시 40분까지 도착해 책상마다 녹음기 한 대를 놓아야 합니다. 회원의 이어폰과 진행자의 녹음기가 한 사람의 준비물로 묶였다면 독자 조건을 다시 쓰세요.

## 모임 정보 접수 양식 작성하기

예시 한 쌍을 먼저 읽으세요. 입력이 “토요일 3시, 도서관 2층에서 만나요”라면 모범 출력의 첫 줄은 “모임 일시: 토요일 3시”, 둘째 줄은 “모임 장소: 도서관 2층”입니다. 이제 다른 장소·일시로 직접 가상 입력 한 건과 출력 두 줄을 쓰고 세 줄을 내 지시문에 붙이세요. C3에 시험한 뒤 C5로 다시 보냅니다. C5에는 숫자와 날짜가 보이지만 그 날짜는 제출 기한입니다. 날짜를 찾는 데 그치지 말고 어느 사건의 날짜인지 읽어 보세요.

| 원문 | 기대한 모임 일시 / 모임 장소 | 실제 응답 | 근거가 없는 부분과 수정 지시 |
|---|---|---|---|
| C3 | | | |
| C5 | | | |
| 짝이 새로 쓴 공지 | | | |

C3에서는 5월 21일 금요일 오후 4시와 장소 미정, C5에서는 두 항목 모두 미정이어야 합니다. 세 번째 입력은 답을 미리 알려 주지 말고 서로 바꿔 시험하세요. 다음 시간에는 같은 대화에서 날짜만 정정해 보겠습니다.
