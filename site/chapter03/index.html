02

print()와 return의 차이

함수의 반환값은 호출한 쪽에서 다시 계산에 쓸 수 있는 값입니다. 어떤 입력을 받을지, 처리할 수 없는 입력을 만나면 어떤 예외를 낼지도 함께 설계합니다.

함수 안에서 결과를 출력하는 것과 결과를 호출한 곳으로 돌려주는 일은 따로 일어납니다. 다음 계산에 쓸 값은 return으로 보냅니다.

셀 01 · print()만 호출한 함수의 반환값

함수 안에서 출력한 값과 호출 결과로 저장한 값을 비교합니다.

실행 결과

30
None

첫 줄의 30은 함수 안에서 찍혔습니다. 두 번째 줄의 None은 return 없이 끝난 함수가 돌려준 값입니다.

다음 계산에 사용할 값은 saved에 저장됩니다. saved에 10을 더하면 TypeError가 납니다. 30을 보여 준 print의 일은 그 줄에서 끝났기 때문입니다. 다음 셀처럼 함수에서 정수를 반환하면 호출한 쪽에서 그 수로 계산할 수 있습니다.

셀 02 · return과 int() 형 변환

앞뒤 공백을 지우고 정수로 변환한 다음 허용 범위를 확인합니다.

실행 결과

40

함수가 정수 30을 반환했으므로 10을 더하면 40이 됩니다. -> int는 반환값의 의도를 알려 주고, 범위는 if 문에서 직접 검사합니다.

함수의 매개변수와 return

parse_minutes(" 30 ")를 호출하면 text는 공백이 포함된 문자열을 받습니다. int(text.strip())가 만든 정수는 minutes라는 지역 변수에 저장됩니다.

return은 결과를 호출한 자리로 돌려주고 해당 함수 실행을 끝냅니다. print는 화면에 보여 줄 뿐 호출자에게 계산 결과를 돌려주는 역할을 하지 않습니다. return을 쓰지 않은 함수의 반환값은 None입니다.

호출이 끝나면 함수 밖에서는 지역 변수 minutes를 바로 읽을 수 없습니다. 호출한 곳에서 값을 계속 쓸 때는 minutes = parse_minutes(" 30 ")처럼 반환값을 받아 둡니다.

03

raise와 try/except로 ValueError 처리

화면에 어떤 안내를 띄울지는 함수를 호출한 쪽에서 정합니다. 계산 함수는 잘못된 입력으로 계속 진행하지 않도록 예외를 올립니다.

셀 03 · try/except로 ValueError 처리

이번에는 정수 변환은 성공하고 범위 검사에서 멈춥니다.

실행 결과

분은 0~480 사이여야 합니다.

‘분은 0~480 사이여야 합니다.’라는 문구가 나옵니다. raise가 실행되면 return까지 가지 않고 호출자의 except로 이동합니다.

ValueError를 받는 호출자

함수 안에서 raise ValueError(...)가 실행되면 그 함수의 나머지 줄은 건너뜁니다. 호출한 쪽의 try 블록에서 예외가 발생한 위치를 찾고, except ValueError가 어떤 메시지를 출력하는지 이어서 읽어 보세요.

과제 04 · 허용 범위의 경계 테스트

480을 넣어 반환값이 정수 480인지 assert로 확인하고 그 값을 표시하세요.

assert 뒤에는 참이어야 하는 조건을 씁니다. 조건이 참이면 다음 줄로 넘어가고 거짓이면 AssertionError에서 멈춥니다. 성공할 때 assert 자체는 아무것도 출력하지 않습니다.

풀이와 실행 결과 보기

실행 결과

480

480이 보이면 assert를 통과했습니다. ‘480 이상’을 막도록 조건을 잘못 바꾸면 허용해야 할 480에서도 예외가 납니다.

정상값·경곗값·예외 테스트

assert 뒤의 조건이 거짓이면 AssertionError가 발생합니다. 정답을 눈으로 보는 대신 예상 결과를 코드에 적어 바뀐 동작을 빠르게 찾습니다. assert는 개발용 검사에 사용하며 운영 입력 검증은 앞서 작성한 if와 raise로 유지합니다. Python 최적화 옵션에서는 assert가 생략될 수 있습니다.

정수 변환에 실패하는 입력은 ‘내일’, 변환 후 범위 검사에 걸리는 입력은 ‘481’입니다. 오류가 난 줄은 다르지만 같은 ValueError이므로 과제 06에서는 한 except 블록으로 안내할 수 있습니다.

04

타입 힌트와 입력 정규화 함수

제목 안에 붙은 여러 공백은 한 칸으로 합치고, 시간은 앞에서 만든 함수에 맡깁니다. 두 함수는 키보드나 파일 없이 문자열만 주면 확인할 수 있습니다.

타입 힌트와 입력 검증

title: str은 문자열을 받을 의도, -> str은 문자열을 반환할 의도를 나타내는 타입 힌트입니다. 실행기가 이 표기만 보고 값을 자동 변환하거나 잘못된 타입을 모두 막지는 않습니다. 입력 규칙과 검사 코드를 함께 작성해야 합니다.

normalize_title은 공백으로 나눈 단어들을 공백 하나로 다시 합칩니다. " ".join(목록)은 문자열 목록 사이에 공백을 넣어 연결합니다. parse_minutes는 정수로 바꾼 뒤 이 수업 예제의 허용 범위인 0~480분인지 확인합니다. 이 범위는 Python의 제한이 아니라 과제 규칙입니다.

함수허용 입력결과·실패

parse_minutes정수를 나타내는 문자열0~480 정수; 변환 실패·범위 밖이면 ValueError

복습과 실습 점검

parse_minutes(" 0 ")는 허용 범위의 시작값인 0을 반환합니다. "-1"은 정수로 바꾸는 데 성공한 뒤 범위 검사에서 예외가 납니다. 두 입력을 같은 0으로 저장하면 실제로 0분을 기록한 경우와 입력을 고쳐야 할 경우를 구분할 수 없습니다.
