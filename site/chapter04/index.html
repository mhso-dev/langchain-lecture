02

__init__과 self로 인스턴스 상태 저장

클래스는 객체가 가질 속성과 메서드를 정의합니다. 같은 클래스로 만든 두 객체에도 각자의 상태가 있습니다.

클래스는 새 기록에 어떤 값을 담고 어떤 일을 시킬지 정합니다. StudyRecord를 두 번 부르면 같은 규칙을 따르는 별개의 객체가 생깁니다.

셀 01 · __init__과 인스턴스 생성

생성 시 받은 값과 기본 완료 표시가 어떻게 저장되는지 보세요.

실행 결과

{'title': 'Python 기초', 'minutes': 30, 'done': False}

done에 False가 들어 있습니다. self는 메서드를 호출한 바로 그 객체입니다. to_dict는 지금 그 객체 안에 든 값들을 사전으로 꺼냅니다.

서로 다른 두 수업의 완료 상태

self는 이번에 메서드를 호출한 객체를 가리킵니다. 같은 클래스로 수업 두 개를 만들고 한쪽의 완료 상태만 바꿔 보세요. 두 객체의 제목과 상태를 각각 읽으면 어느 데이터가 함께 묶이는지 확인할 수 있습니다.

셀 02 · 인스턴스별 속성 분리

첫 기록만 완료로 바꾼 뒤 방금 만든 둘째 기록을 확인합니다.

실행 결과

False가 나옵니다. first.mark_done()의 self는 first를 가리키므로 second.done은 처음 값 그대로입니다.

second를 만들 때 StudyRecord를 다시 호출한 줄을 보세요. 그 줄을 second = first로 바꾸면 두 이름이 한 기록을 가리킵니다. 이때 first.mark_done()을 실행하면 second.done으로 읽어도 True입니다. 별도의 기록이 필요할 때 객체를 한 번 더 만드는 이유입니다.

속성과 인스턴스 메서드

객체는 값을 담고 그 값에 관련된 동작을 제공할 수 있습니다. 클래스는 그런 객체를 만드는 정의입니다. StudyRecord("Python", 30)을 호출하면 기록 객체 하나가 만들어집니다. 다른 인자로 다시 호출하면 별도 객체가 생깁니다.

__init__은 새 인스턴스의 초기 상태를 정하는 메서드입니다. self는 그 메서드가 다루는 객체 자신을 가리키는 관례적 이름입니다. self.title처럼 적으면 해당 객체의 속성에 저장합니다. 메서드는 클래스 안에 정의한 함수입니다.

first.mark_done()을 호출할 때 Python이 first를 self로 전달합니다. second.done은 바꾸지 않았으므로 False로 남습니다. 이 예제의 생성자는 정리된 문자열과 정수를 받는다고 가정하며 입력 검증은 뒤의 함수가 맡습니다.

first.mark_done()first.doneTrue

04

import로 모듈의 함수 호출

모듈은 이름을 통해 불러 쓸 수 있는 코드 묶음입니다. math를 예로 들어 모듈과 그 안의 함수를 구별해 본 뒤, 수업 예제의 studylog.models와 StudyRecord에도 같은 읽기 순서를 적용해 보세요.

패키지 안의 상대 import

from .models import StudyRecord에서 점 하나는 같은 패키지를 가리킵니다. service 모듈은 클래스 정의를 복사하지 않고 models에 있는 정의를 사용합니다.

셀 06 · import math와 math.isqrt()

점 왼쪽에서 모듈을 찾고 오른쪽의 함수를 부릅니다.

실행 결과

5

isqrt(25)의 결과는 정수 5입니다. import math로 가져온 이름은 모듈이므로 math.isqrt라고 적습니다. 다음 셀의 from .models import StudyRecord는 클래스 이름을 직접 가져옵니다.

모듈 경계와 import

from studylog.models import StudyRecord는 studylog 패키지의 models 모듈에서 클래스를 가져옵니다. import된 모듈의 최상위 문장은 처음 불러올 때 실행될 수 있습니다. 입력 요청이나 예제 실행을 아무 곳에나 두면 다른 모듈에서 가져올 때도 실행되어 불편합니다.

to_dict()는 호출한 시점의 title·minutes·done으로 새 사전을 만듭니다. 먼저 사전을 얻고 나서 객체에 mark_done()을 호출해도 앞서 얻은 사전의 done은 그대로입니다. 최신 상태를 내보내려면 변경 뒤에 메서드를 다시 호출합니다.

모듈 분리와 파일별 역할

models.py
class StudyRecord:
    def __init__(self, title):
        self.title = title
service.py
from .models import StudyRecord

def make_record(title):
    return StudyRecord(title.strip())

제공 셀이 임시 studylog 폴더에 두 모듈을 만듭니다. models에서 클래스를 정의한 줄과 service에서 그 클래스를 불러오는 줄을 나란히 읽으세요.

models.py에서 기록의 구조를 정의하고 service.py에서 그 기록을 사용합니다. from .models의 점은 같은 패키지 안에서 models를 찾는다는 뜻입니다. 먼저 이 두 파일의 내용만 읽고 아래 제공 셀을 통째로 실행하세요.
