# 11월 26일 수업표와 교재 이동

[편성 원문](../curriculum.md)과 배포용 일차 120개를 대조했다. 일반 수업 600시간, 중간 프로젝트 80시간, 최종 프로젝트 248시간, 특강·현장실습 32시간이다. 특강 4일은 기존 현장 활동과 노트북에 개별 주소를 부여했다.

| 일차 | 수정 범위 |
|---|---|
| 8·17·19 | 가상 문의의 사람·모델 답변 비교, SDK 도구 선택 추적, LCEL 4시간과 별도 SDK 실습 4시간 |
| 35·36·39 | 정답 근거, 검색 순위와 답변 평가, 대표 실패 추적 |
| 64·67 | 승인 전후 저장 횟수, 기대 경로와 실제 도구 인자 |
| 80 | 투두 CRUD와 요구 변경. 이전 판의 하네스는 선택 자료 |
| 81~85 | 실행 추적, RAG 평가, 도구 경로 평가, 회귀 검사, 시험 배포 피드백 |
| 1~120 | 상단 전체 목차·일차 선택·이전·다음, 하단 순차 이동 |

## 검수와 실행

- 독립 교육 검수 후 시행 이전 날짜, 데이터셋 초기 생성, 회귀 문항 재등록, 승인 인자, 지연·비용 기준선을 수정했다. 17일차는 실제 교재의 함수 두 개로 추적하고 19일차는 가상 응답을 실제 SDK로 읽는다.
- macOS, Python 3.12.15에서 본문을 바꾼 14일의 학생 셀과 풀이 셀을 각각 새 작업 폴더에서 실행했다. 19일차 SDK 과제는 정상 조회 1회, ID 누락 0회, 없는 ID 조회 1회를 확인했다. 81~85일차는 기본 셀과 풀이를 실행했다. 계정 연결 셀은 학생이 준비한 수업용 환경에서 켠다.
- 한국어 산문은 수업표의 의미·일차·시간·기대값과 대조했다. 문서 공개 범위를 판정하지 않아 외부 맞춤법 서비스 전송은 생략했다.
- 빌드 후 정적 HTML 131개와 116쌍의 교재·노트북, 120×120 선택 링크, 양방향 순차 링크 238개를 검사했다. 브라우저와 노트북의 원격 검사 결과는 이 변경의 GitHub Actions에서 확인할 수 있다.

## 확인 필요 항목

학생 LangSmith 계정에서 수집한 실제 실행과 실험, 팀 서비스 시험 배포, 학생 Windows/WSL 환경과 8시간 수업 소요 시간은 검증 대상에 남아 있다. 이번 편집으로 기존 장의 교육 완료 상태를 올리지 않았다.
