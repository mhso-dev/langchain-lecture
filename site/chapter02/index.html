02

리스트 인덱스와 딕셔너리 키

리스트에서는 몇 번째 값인지, 딕셔너리에서는 어떤 키인지 지정해 값을 꺼냅니다. 두 구조가 겹치면 바깥쪽부터 한 단계씩 접근합니다.

리스트에서는 순서로, 딕셔너리에서는 키로 값을 찾습니다. 자료의 바깥쪽에서 안쪽으로 한 단계씩 내려가 보세요.

리스트 인덱스와 딕셔너리 키

리스트는 0부터 시작하는 위치 번호로 값을 찾습니다. 길이가 3이면 사용할 수 있는 0 이상의 인덱스는 0·1·2입니다. topics[3]은 네 번째 값을 요구합니다. append()는 맨 뒤에 값을 하나 추가합니다.

딕셔너리는 키와 값의 쌍을 담습니다. record["name"]은 name 키의 값을 읽습니다. 없는 키를 대괄호로 읽으면 KeyError, get(키, 기본값)을 쓰면 키가 없을 때 기본값을 얻습니다. get은 값이 None인 경우까지 기본값으로 바꾸지는 않습니다.

셀 01 · 딕셔너리 키와 리스트 인덱스 연결

records에는 제목이 있는 기록 세 건이 차례로 들어 있습니다.

data["records"]는 기록 전체입니다. 여기에 [0]을 붙이면 첫 번째 기록 한 건이 남고, 그 기록에서 ["minutes"]를 읽으면 숫자 30이 나옵니다. 두 번째 기록을 읽으려면 어느 대괄호의 숫자를 바꿔야 할까요?

실행 결과

30

30은 첫 기록의 시간입니다. [0]은 첫 번째 기록을, ["minutes"]는 그 기록의 시간을 골랐습니다.

변수 대입과 자료형

변수는 값을 다시 사용할 수 있도록 붙인 이름입니다. =는 오른쪽 결과를 왼쪽 이름에 연결합니다. 두 값이 같은지 비교할 때는 ==를 씁니다. 위에서 아래로 실행되므로 값을 만들기 전에 사용하면 NameError가 납니다.

따옴표 안의 "30"은 문자열(str)입니다. 정수(int) 30과 겉모양이 같아도 덧셈의 동작이 다릅니다. 소수는 float, 참과 거짓은 bool, 값이 없다는 표시는 None으로 표현합니다.

중첩 리스트·딕셔너리 접근

data는 딕셔너리이고 records 키의 값은 리스트입니다. 리스트 안의 원소는 각각 딕셔너리입니다. 먼저 data["records"]로 목록을 얻고, for로 기록 하나를 꺼낸 뒤 record["title"]을 읽습니다. 구조를 건너뛰어 data["title"]이라고 쓰면 해당 키가 없습니다.

예제의 입력은 minutes가 정수이고 done이 bool인 정상 데이터로 제한합니다. 외부 입력의 검증과 실패 처리는 3장 이후에 추가합니다.

셀 02 · str.strip()으로 공백 제거

실행 결과

Python 기초

Python 기초가 나옵니다. strip은 정리한 문자열을 돌려줍니다. first 안의 title을 새 값으로 바꾸지는 않습니다.

문자열 공백 처리와 분할

strip()은 문자열 양끝의 공백을 지웁니다. replace(찾을 글자, 새 글자)는 일치하는 부분을 바꾼 새 문자열을 만듭니다. 원래 변수에 다시 대입하지 않으면 원본 변수는 바뀌지 않습니다.

split()은 공백을 기준으로 나눈 문자열들을 리스트로 반환합니다. 리스트는 여러 값을 순서대로 담는 자료형이며 다음 절에서 직접 꺼내 봅니다. len()은 길이, in은 포함 여부를 확인합니다.

조건문과 반복문

if 뒤의 조건이 참이면 들여쓴 부분을 실행합니다. 거짓일 때는 else 부분을 실행합니다. : 뒤에 줄을 바꾸고 공백 4칸을 넣어 같은 묶음을 표시하세요. >=는 이상, >는 초과입니다. and는 두 조건을 모두 만족할 때, or는 하나 이상 만족할 때 참입니다.

for는 리스트의 값을 하나씩 꺼내 반복 변수에 넣습니다. total을 반복문 바깥에서 0으로 시작하면 값을 누적할 수 있습니다. 반복문 안에서 0으로 만들면 이전 합계가 사라집니다.

JSON과 Python 값 변환

JSON은 프로그램 사이에서 데이터를 주고받을 때 사용하는 텍스트 형식입니다. 딕셔너리와 비슷하게 보이지만 JSON 텍스트와 Python 딕셔너리는 서로 다른 값입니다. json.loads는 JSON 문자열을 Python 값으로 읽고, json.dumps는 Python 값을 JSON 문자열로 만듭니다.

JSON의 문자열과 키는 큰따옴표를 사용합니다. true·false·null은 Python의 True·False·None에 대응합니다. 작은따옴표로 쓴 Python 딕셔너리 표시를 그대로 JSON이라고 보내면 오류가 날 수 있습니다.
