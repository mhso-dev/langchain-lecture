셀 06 · 수강료가 발표된 새 원문 만들기

‘미발표’라는 고정 답을 외운 요청이라면 다음 입력에서 어떻게 될까요?

원문에서 수강료만 바꾸었습니다. 요청은 그대로 두고 새 원문으로 확인해야 무엇이 응답 차이를 만들었는지 알 수 있습니다.

실행 결과

06

관련 개념 더 읽기

좋은 요청의 기준부터 정하기

프롬프트는 모델에 보내는 요청입니다. 길고 정중하다는 이유만으로 좋은 프롬프트가 되지는 않습니다. 사용자가 원하는 결과와 확인 기준이 드러나야 결과를 비교할 수 있습니다.

오늘은 가상 설명회 안내에서 일정과 비용 정보를 추출합니다. 처음에는 “이 안내문 정리해줘”만 요청하고 응답을 보관합니다. 잘못된 응답을 유도하기 위해 일부러 사실과 다른 자료를 주지는 않습니다.

목표·맥락·제약·형식 나누기

목표는 결과로 무엇을 할 것인지를 적는 부분입니다. “요약”보다 “예비 수강생이 신청 마감을 놓치지 않도록 일정과 준비 사항을 정리”라고 쓰면 선택할 정보가 분명해집니다. 맥락에는 독자와 제공 자료의 범위를 넣습니다.

네 요소의 예
요소이번 과제의 문장
목표예비 수강생에게 설명회 일정을 전달한다.
맥락첨부한 가상 교육센터 안내문만 사용한다.
제약미발표 수강료와 미확정 다시보기를 확정하지 않는다.
형식항목 / 내용 / 근거 표로 쓴다.
모호한 요청을 수정하기

“자세히”와 “깔끔하게”는 사람마다 기준이 다릅니다. 독자, 포함할 항목, 길이 또는 형식을 구체적으로 정하면 결과를 확인하기 쉽습니다. 다만 세부 조건을 많이 넣을수록 서로 모순되는 조건이 없는지 검토해야 합니다.

기준선과 비교할 때는 같은 서비스·같은 자료를 사용하고 새 대화에서 실행합니다. 이전 응답을 붙여 넣고 수정시키는 실험은 대화 맥락이 추가되므로 별도로 기록합니다. 출력은 매번 달라질 수 있어 한 번의 성공이 모든 입력의 성공을 보장하지 않습니다.

예시는 규칙을 보여 주기 위해 사용하기

원하는 출력의 모양을 말로 설명하기 어려울 때 작은 예시를 붙일 수 있습니다. 예시가 정답 그 자체라면 모델이 복사하기만 할 수 있으므로 별도의 가상 입력으로 형식을 보여 줍니다.

분류 예시는 이름만 제시하는 것보다 기준을 함께 적어야 합니다. 예를 들어 “미정”이라는 표시가 정보가 없는 경우인지 아직 결정되지 않은 경우인지 설명하세요. 예시와 규칙이 충돌하면 예시부터 고칩니다.

실패 유형에 맞춰 한 가지씩 바꾸기

틀린 결과를 발견하면 요청 문장만 탓하지 말고 입력 자료, 출력 요구, 모델 응답을 나누어 봅니다. 자료에 없는 정보를 묻는 경우와 자료에 있는 정보를 놓친 경우의 수정 방법은 다릅니다.

예를 들어 “비용은 무료”라고만 답했다면 설명회 참가비와 교육과정 수강료를 구분하라는 조건을 추가합니다. 표 대신 산문을 내놓았다면 표의 열 이름을 명시합니다. 여러 조건을 한꺼번에 바꾸면 무엇이 효과가 있었는지 설명하기 어렵습니다.

실패와 변경
관찰한 실패원인 후보변경 실험
수강료까지 무료라고 함서로 다른 비용을 합침두 비용을 별도 행으로 요구
다시보기를 제공한다고 함미확정을 확정으로 바꿈근거가 없거나 미확정이면 그 상태 표시
날짜 하나만 표시행사와 마감일을 합침행사 일정과 신청 마감 별도 추출
추측 출처 추가근거 범위가 모호제공 자료의 문장만 근거로 요구
처음 보지 않은 입력으로 재확인하기

한 안내문에 맞춘 요청이 다른 안내문에서도 동작하는지 확인해야 합니다. 같은 자료를 반복 수정한 결과만 보면 요청이 그 사례에만 맞춰졌는지 알기 어렵습니다.

동료가 행사 시간·신청 마감·비용 조건을 다르게 쓴 짧은 가상 안내문을 만듭니다. 변경한 프롬프트를 그대로 적용하고 기존 자료와 별도 확인 자료의 결과를 나눠 적습니다. 확인 자료에서 실패했다고 정답을 몰래 바꾸지 말고 새로운 실패 사례로 보관합니다.

프롬프트와 결과를 버전으로 관리하기

프롬프트 파일만 저장하면 왜 바꿨는지 잊기 쉽습니다. 버전, 요청 전문, 변경 이유, 입력 자료 이름, 실행 조건, 결과와 판정을 함께 기록합니다. 짧은 실험이라도 처음 버전을 덮어쓰지 않아야 비교가 가능합니다.

이 검사는 버전 중복과 빈 기록만 찾습니다. 요청의 품질이나 사실 정확성을 자동으로 판정하지 않습니다.
