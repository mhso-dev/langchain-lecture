06

OpenAI Responses API의 요청·응답 구조 심화 읽기

API·SDK·토큰의 관계

API는 프로그램이 서비스와 요청·응답을 주고받는 규약입니다. Python SDK는 그 규약을 Python 객체와 메서드로 사용하도록 돕는 라이브러리입니다. SDK를 설치하는 것과 서버에 모델 요청을 보내는 것은 별개의 일입니다.

모델은 요청의 입력을 처리하고 출력을 생성합니다. 토큰은 모델이 텍스트 등을 처리할 때 사용하는 단위이며 한국어 글자 수와 일치하지 않습니다. 사용량 필드의 입력 토큰·출력 토큰과 답변 글자 수를 같은 값으로 취급하지 않습니다.

컨텍스트는 모델이 이번 요청에서 참고할 입력 범위입니다. 긴 문서를 넣는다고 전체 내용을 정확히 기억한다는 뜻은 아닙니다. 모델 선택에는 기능 지원, 입력 길이, 응답 품질, 지연, 비용 조건을 함께 확인해야 합니다. 이번 교재는 특정 모델을 모든 과제에 최선이라고 정하지 않습니다.

SDK 요청 함수

ask는 클라이언트, 모델 이름, 질문을 입력받습니다. instructions에는 응답 방식, input에는 사용자 메시지를 전달합니다. max_output_tokens는 출력의 상한이며 항상 그만큼 출력하거나 같은 길이의 문장을 만든다는 뜻은 아닙니다.

함수 안에서 요청이 끝난 뒤 응답 상태와 텍스트를 반환합니다. 호출 한 번의 성공이 내용의 정확성까지 보장하지 않으므로 10장의 원문 대조 기준을 함께 적용합니다.

응답 객체의 본문과 사용량

Responses API의 output에는 텍스트 외의 항목도 들어갈 수 있습니다. 첫 번째 항목의 첫 번째 필드가 항상 답변이라고 가정하지 않고 SDK의 output_text를 사용합니다. status와 usage도 따로 확인합니다.

이번 모의 응답은 항상 “가상 안내를 확인했습니다.”를 반환합니다. 질문을 바꾸어도 같은 답이 나오는 것은 모델이 실행되지 않기 때문입니다. 이를 답변 모델의 성능으로 평가하면 안 됩니다.

API 실패 유형과 실호출 조건

실제 실행은 강사가 승인한 계정과 예산이 준비되었을 때만 --live를 붙입니다. OPENAI_MODEL에는 해당 계정에서 이용 가능하고 Responses API를 지원하는 모델을 지정합니다. 이 자료는 실제 모델 호출을 검증했다고 주장하지 않습니다.

실제 클라이언트는 20초 시간 제한과 자동 재시도 0회를 사용합니다. 연결·인증·한도 오류를 만났을 때 무한히 재호출하지 않기 위한 수업 설정입니다. 기록에는 오류 종류와 HTTP 상태 코드만 남기고 키·헤더·예외 본문 전체를 출력하지 않습니다.
