# 실제 모델 수업과 실습 편성 · 2026-11-26

120일 수업표, 일반 수업 75개 장, 기존 개인 과제와 팀 프로젝트 안내를 대조했다. 06_LLM의 StateGraph 기초와 Workflows vs Agents에서는 하나의 그래프에서 상태, 리듀서, 노드 연결 또는 여러 호출 패턴을 연속해 다룬다. 이번 개정에서는 세부 자료를 옮겨 읽을 수 있게 각 일반 수업에 관련 예제, 실패 조건과 학생 산출물을 연결했다. 일반 수업 75일 모두에 연관된 장의 코드, 예제 출력, 결과 해설을 본문에 펼치고 입력 준비부터 다시 실행할 수 있는 노트북을 연결했다.

- 일반 수업 75일과 현장 활동 4일은 개인 실습, 프로젝트 41일은 팀 산출물 점검에 60~120분을 사용한다. 개인 과제를 따로 더해 8시간을 넘기지 않는다. 첫날에는 CSV 파일을 만들고 새 커널에서 결과를 복원한다.
- 75~80일은 배포 상태 검사, CI 회귀 검사, CD 조건과 복구, UI, API 충돌, 변경 요청 인수 순서로 Codex를 사용한다. 기존 수업과 결합한 32시간(4·4·4·6·6·8시간)이다. 중간 프로젝트 80시간, 최종 프로젝트 248시간, 전체 960시간을 유지했다.
- OpenAI SDK와 LangChain 예제의 역할을 구분했다. 모델에게 판단을 맡길 때는 실제 API를 호출한다. 입력 검증·조회·중복 방지처럼 코드가 직접 결정하는 부분은 독립적으로 시험한다.

## 실행 확인

11~17·19·24·34·55·56·62·63·66장의 학생 실행 또는 정답 경로를 실제 OpenAI API에 연결했다. 13장의 자유 텍스트 분류가 허용 라벨을 벗어나는 실행을 발견해 구조화 출력으로 바꾸고 재실행했다. 62장은 실제 모델이 요일 인자를 선택하고 MCP로 조회한 결과를 확인했다. 같은 커널의 비동기 HTTP 연결을 재사용하도록 검증기의 이벤트 루프를 조정한 뒤 HTTP 전송 정답까지 실행했다.

주제별 통합 노트북 중 구조화 출력, RAG, LangGraph, 검색 도구, 도구 루프 5곳에 실제 모델 셀을 추가해 실행했다. 모델의 정확한 문구와 호출 ID는 실행마다 달라진다. 평가에서는 근거·도구 인자·최종 상태를 비교한다. 외부 키를 제공하지 않는 CI에서는 실제 호출이 필요한 검사를 미실행으로 표시한다. 코딩 보조 시간을 포함한 수업의 소요 시간과 학습 난이도는 편성 목표이며 수강생 대상 실측값은 아니다.
