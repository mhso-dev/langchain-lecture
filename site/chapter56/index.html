호출 한도로 중복 조회 한 번만 허용하기

55장의 정상 호출을 그대로 두 번 제안한 경우를 시험합니다. 허용된 호출과 막힌 호출을 따로 남기면 다음 장에서 Skill이 쓸 도구 이름을 고를 수 있습니다.

call = previous["call"]
def budget(calls, limit):
    allowed, blocked = [], []
    for item in calls:
        if len(allowed) < limit:
            allowed.append(item)
        else:
            blocked.append(item["name"])
    return allowed, blocked
allowed, blocked = budget([call, call], 1)
print(len(allowed), blocked)
