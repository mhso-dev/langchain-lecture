# 공지와 대여 문의 답변 대조 예시

아래 답은 집필자가 원문을 읽고 쓴 예시다. 모델을 호출한 학생은 실제로 받은 응답을 그대로 보관하고, 표현이 달라도 원문의 조건이 남았는지 확인한다.

## 공지

| 입력 | 사람이 확인한 답과 근거 |
| --- | --- |
| C1, C2 | 5월 21일 금요일 오후 4시는 같다. C1의 장소는 가온관 201호, C2는 가온관 305호다. |
| C1 독자 변경 | 신입 회원에게는 “이어폰을 챙겨 오세요.” 진행자에게는 “오후 3시 40분까지 도착해 녹음기를 책상마다 한 대씩 놓아 주세요.” 오후 4시보다 20분 이르다. |
| C3, C5 | C3의 일시는 5월 21일 금요일 오후 4시이고 장소는 미기재다. C5의 5월 28일 금요일 오전 11시는 파일 제출 마감이다. 동아리 게시판은 파일을 올릴 곳이며 다음 모임의 장소는 알 수 없다. 추출 항목이 모임 일시·장소라면 C5의 두 칸을 비운다. |
| C4 | 정정까지 읽으면 5월 22일 토요일 오후 4시, 가온관 305호다. 세 번째 발화만 받은 새 대화에서는 일시와 장소를 되묻는다. |
| C5 한 문장 | “5월 28일 금요일 오전 11시까지 파일 제목에 녹음 장소를 넣어 동아리 게시판에 올려 주세요.” 파일을 고르는 주체를 덧붙인다면 진행자라고 쓴다. |

## 대여 문의

| 입력 | 사람이 쓴 답변 예시 | 근거 |
| --- | --- | --- |
| Q1 | 친구는 대신 받을 수 없습니다. 6월 10일 오후 3~5시에 학생증을 가지고 가온관 1층 안내 데스크로 오세요. 기기와 케이블은 6월 11일 오후 5시까지 같은 곳에 돌려주세요. | R2, R3 |
| Q2 | “승인받은 회원은 대여일 오후 3~5시에 학생증을 가지고 가온관 1층 안내 데스크에서 기기를 직접 받습니다. 다음 날 오후 5시까지 기기와 케이블을 같은 곳에 돌려주세요.” 사실 검토에서는 대리 수령과 이틀 뒤 반납을 짚는다. 표현 검토에서는 누가 무엇을 어디에 가져갈지 읽히는지 본다. | R2, R3 |
| Q3 | A형과 B형 중 어느 기종이 필요하세요? 몇 월 며칠에 빌리실 예정인가요? | R1 |
| Q4 | 6월 11일 정오까지 원래 신청 게시글에 하루 연장을 요청하는 댓글을 남겨 주세요. 담당자의 승인 댓글이 달려야 반납일이 6월 12일로 바뀝니다. | R3, R4 |
| Q5 | 내일 대여하려면 오늘 오후 5시까지 신청해야 합니다. 지금은 신청 마감이 지났고 승인도 받지 않았으므로 바로 수령할 수 없습니다. | R1, R2 |

Q4를 검토할 때 처음부터 위 답을 넣으면 수정 횟수는 0회다. 처음 답에 승인이 빠졌고 한 번 고쳐 승인 조건을 채웠다면 1회에서 통과한다. 한 번 고친 뒤에도 승인이 빠졌다면 1회에서 멈추고 미해결 사유를 남긴다. 이는 세 경로를 판별할 때 쓰는 기대 동작이다.
