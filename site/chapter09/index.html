02

지시문에 출력 조건 추가

프롬프트에는 모델이 읽을 자료와 답변에 지킬 조건을 담습니다. 한 조건씩 바꿔야 응답의 어느 차이가 그 수정과 관련 있는지 살필 수 있습니다.

기준선은 수정 전 상태입니다. 원문과 첫 요청을 함께 남겨 두어야 어떤 수정이 어떤 오류를 줄였는지 다시 확인할 수 있습니다.

목표·맥락·제약·출력 형식

목표는 결과로 무엇을 할 것인지를 적는 부분입니다. “요약”보다 “예비 수강생이 신청 마감을 놓치지 않도록 일정과 준비 사항을 정리”라고 쓰면 선택할 정보가 분명해집니다. 맥락에는 독자와 제공 자료의 범위를 넣습니다.

네 요소의 예
요소이번 과제의 문장
목표예비 수강생에게 설명회 일정을 전달한다.
맥락첨부한 가상 교육센터 안내문만 사용한다.
제약미발표 수강료와 미확정 다시보기를 확정하지 않는다.
형식항목 / 내용 / 근거 표로 쓴다.

셀 01 · 원문 고정과 프롬프트 기준선

가상 교육센터 안내문에서 참가비와 수강료를 언급한 문장을 추출합니다.

실행 결과

설명회 참가비는 무료다. 교육과정의 수강료는 아직 발표하지 않았다.

설명회 참가비와 교육과정 수강료가 한 문장 안에서도 구분됩니다. v1에는 요약할 독자와 구분할 항목이 모두 빠져 있습니다.

원문이 무료라고 명시한 항목은 설명회 참가비입니다. 이 문장을 ‘무료 교육과정 설명회’라고 줄이면 교육과정까지 무료인 것처럼 읽힙니다. 프롬프트에 두 금액을 따로 적으라는 조건을 더한 뒤, 같은 안내문으로 두 항목이 어떻게 채워지는지 비교하세요.

프롬프트의 수용 기준

프롬프트는 모델에 보내는 요청입니다. 길고 정중하다는 이유만으로 좋은 프롬프트가 되지는 않습니다. 사용자가 원하는 결과와 확인 기준이 드러나야 결과를 비교할 수 있습니다.

오늘은 가상 설명회 안내에서 일정과 비용 정보를 추출합니다. 처음에는 “이 안내문 정리해줘”만 요청하고 응답을 보관합니다. 잘못된 응답을 유도하기 위해 일부러 사실과 다른 자료를 주지는 않습니다.

과제 02 · 프롬프트 조건 한 가지 추가

v1은 그대로 두고 비용 두 가지를 따로 적으라는 문장만 덧붙여 출력하세요.

풀이와 실행 결과 보기

실행 결과

이 안내문 정리해줘. 설명회 참가비와 교육과정 수강료를 따로 적어주세요.

바뀐 조건이 하나라서 두 응답의 차이를 해석하기 쉽습니다. 더 정확한 응답이 나오는지는 실제 응답을 얻어 원문과 대조해야 합니다.

모호한 지시의 구체화

“자세히”와 “깔끔하게”는 사람마다 기준이 다릅니다. 독자, 포함할 항목, 길이 또는 형식을 구체적으로 정하면 결과를 확인하기 쉽습니다. 다만 세부 조건을 많이 넣을수록 서로 모순되는 조건이 없는지 검토해야 합니다.

기준선과 비교할 때는 같은 서비스·같은 자료를 사용하고 새 대화에서 실행합니다. 이전 응답을 붙여 넣고 수정시키는 실험은 대화 맥락이 추가되므로 별도로 기록합니다. 출력은 매번 달라질 수 있어 한 번의 성공이 모든 입력의 성공을 보장하지 않습니다.

셀 03 · 프롬프트 수정 전후 응답 비교

다음 두 문장은 차이를 설명하기 위해 쓴 가상 응답입니다. v1을 받은 예시 응답은 ‘설명회와 교육과정 모두 무료입니다.’라고 적었습니다. 비용 구분 조건을 덧붙인 요청의 예시는 어떻게 다른지 읽어 보세요.

실행 결과

설명회 참가비는 무료입니다. 교육과정 수강료는 아직 발표하지 않았습니다.

두 응답에서 ‘무료’의 범위가 달라졌습니다. 수정한 예시는 원문에서 확인할 수 있는 설명회 참가비만 무료로 적었습니다. 이는 작성 예시 두 개의 비교이므로 조건 하나만 고치면 모든 모델이 이렇게 답한다는 결론은 낼 수 없습니다.

실패 유형별 단일 조건 수정

틀린 결과를 발견하면 요청 문장만 탓하지 말고 입력 자료, 출력 요구, 모델 응답을 나누어 봅니다. 자료에 없는 정보를 묻는 경우와 자료에 있는 정보를 놓친 경우의 수정 방법은 다릅니다.

예를 들어 “비용은 무료”라고만 답했다면 설명회 참가비와 교육과정 수강료를 구분하라는 조건을 추가합니다. 표 대신 산문을 내놓았다면 표의 열 이름을 명시합니다. 여러 조건을 한꺼번에 바꾸면 무엇이 효과가 있었는지 설명하기 어렵습니다.

실패와 변경
관찰한 실패원인 후보변경 실험
수강료까지 무료라고 함서로 다른 비용을 합침두 비용을 별도 행으로 요구
다시보기를 제공한다고 함미확정을 확정으로 바꿈근거가 없거나 미확정이면 그 상태 표시
날짜 하나만 표시행사와 마감일을 합침행사 일정과 신청 마감 별도 추출
추측 출처 추가근거 범위가 모호제공 자료의 문장만 근거로 요구
03

미정 값의 처리와 원문 대조

요청 문구를 개선했어도 새 응답에 원문에 없는 날짜나 링크가 들어갈 수 있습니다. 형식에 맞게 칸을 채우는 일과 그 칸의 내용이 맞는지는 따로 봅니다.

셀 04 · 미확정 필드의 근거 확인

다음은 실제 모델 출력이 아닌 연습 문장입니다. 근거가 있는지 해당 문장을 찾아 봅니다.

실행 결과

신청 주소는 추후 안내한다.

‘신청 주소는 추후 안내한다.’라고만 적혀 있습니다. 홈페이지라는 새 장소를 근거 없이 추가했습니다.

과제 05 · 근거가 있는 응답 필드 작성

교육과정 수강료를 ‘항목 / 내용 / 근거’ 순서로 기록하세요. 출력에는 학생이 볼 내용과 원문을 함께 담습니다.

풀이와 실행 결과 보기

실행 결과

미발표 교육과정의 수강료는 아직 발표하지 않았다.

‘미발표’로 남겨야 무료 설명회와 혼동하지 않습니다. 근거를 그대로 읽으면 같은 기준으로 다른 행도 점검할 수 있습니다.

예시로 출력 규칙 전달

원하는 출력의 모양을 말로 설명하기 어려울 때 작은 예시를 붙일 수 있습니다. 예시가 정답 그 자체라면 모델이 복사하기만 할 수 있으므로 별도의 가상 입력으로 형식을 보여 줍니다.

분류 예시는 이름만 제시하는 것보다 기준을 함께 적어야 합니다. 예를 들어 “미정”이라는 표시가 정보가 없는 경우인지 아직 결정되지 않은 경우인지 설명하세요. 예시와 규칙이 충돌하면 예시부터 고칩니다.

04

프롬프트 변경 이력과 재시험 입력

원문의 일정·비용을 구분한 뒤에는 요청, 변경 이유, 확인한 입력을 기록합니다. 다음 입력에도 쓸 수 있는 규칙인지 보려면 원문에서 한 조건을 바꿉니다.

프롬프트 버전과 응답 이력

프롬프트 파일만 저장하면 왜 바꿨는지 잊기 쉽습니다. 버전, 요청 전문, 변경 이유, 입력 자료 이름, 실행 조건, 결과와 판정을 함께 기록합니다. 짧은 실험이라도 처음 버전을 덮어쓰지 않아야 비교가 가능합니다.

v1과 v_cost 사이에 추가한 조건은 참가비와 수강료를 나눠 적으라는 한 문장입니다. 셀 03은 미리 써 둔 응답을 출력합니다. 두 요청을 실제 모델에 보낸 결과는 직접 실행한 뒤에만 이력에 넣을 수 있습니다.

셀 06 · 원문 변경 후 프롬프트 재검사

‘미발표’라는 고정 답을 외운 요청이라면 다음 입력에서 어떻게 될까요?

원문에서 수강료만 바꾸었습니다. 요청은 그대로 두고 새 원문으로 확인해야 무엇이 응답 차이를 만들었는지 알 수 있습니다.

실행 결과

설명회 참가비는 무료다. 교육과정의 수강료는 5만 원이다.

새 원문에서 수강료는 5만 원입니다. 지시는 ‘항상 미발표라고 적기’ 대신 ‘이번 자료가 밝힌 상태를 유지하기’여야 바뀐 정보도 전달합니다.

새 입력에 대한 재검증

셀 06에서 바꾼 것은 프롬프트가 아니라 안내문 원문입니다. 이제 교육과정 수강료가 5만 원이므로, 같은 프롬프트로 결과가 또 ‘미발표’가 되면 새 입력을 반영하지 못한 것입니다.

동료가 행사 시간·신청 마감·비용 조건을 다르게 쓴 짧은 가상 안내문을 만듭니다. 변경한 프롬프트를 그대로 적용하고 기존 자료와 별도 확인 자료의 결과를 나눠 적습니다. 확인 자료에서 실패했다고 정답을 몰래 바꾸지 말고 새로운 실패 사례로 보관합니다.

05

복습과 실습 점검

과제 02의 v_cost와 셀 01의 v1을 노트북에 남기고 저장하세요. 인계 메모 예 · 입력은 가상 교육센터 안내, 변경은 설명회 참가비와 과정 수강료를 분리한 조건, 제공 응답의 관찰은 ‘참가비 무료·수강료 미발표’입니다. 실제 서비스에서 얻은 응답은 실행 날짜와 함께 별도로 기록하세요.

프롬프트 설계 복습

10장에서는 안내문 한 건에서 주장마다 근거를 찾습니다. 오늘의 ‘설명회 무료’는 확인한 문장이고 ‘교육과정 무료’는 같은 근거로 쓸 수 없는 문장입니다.

10장에는 저장한 9장 노트북과 원문을 가져갑니다. 과제 02에서 바꾼 요청 한 줄과 셀 03의 예시 응답을 열어 무엇을 따로 확인했는지 설명하세요.
