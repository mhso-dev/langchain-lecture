# Python 문법 실습 기록지

이 기록지는 [실습 노트북](lesson.ipynb)과 함께 씁니다. 코드는 노트북에서 작성하세요. 이 문서에는 실행 전 예상값, 실제 출력과 차이의 원인을 남깁니다. 예제마다 입력을 바꿀 때는 해당 셀 전체를 다시 실행해 처음부터 계산합니다. 모범 풀이와 실행 결과는 노트북의 각 실습 셀 바로 아래에서 펼칠 수 있습니다.

## 1장 · 녹음 길이를 초 단위로 넘기기

녹음 목록에는 숫자와 숫자 모양의 글자가 섞여 있습니다. 편집 프로그램은 총 길이를 초 단위 정수로 받습니다. 아래 세 기록의 초 수를 손으로 먼저 구한 뒤 노트북의 같은 계산식에 차례로 넣으세요. 따옴표도 입력의 일부입니다.

| 기록 | 시간 | 분 | 초 | 예상 초 | 실제 초 |
| --- | --- | --- | --- | --- | --- |
| 소개 | "1" | "02" | 3 | | |
| 소개 사본 | 1 | 2 | 3 | | |
| 인사말 | 0 | "02" | "03" | | |

소개와 소개 사본은 모두 3723초, 인사말은 123초가 되어야 합니다. 전체가 어긋나면 시·분·초가 각각 기여한 초를 따로 계산하세요. 분만 "2분"으로 바꿨을 때 멈춘 줄과 오류 이름을 기록한 뒤 정상 입력으로 되돌립니다.

## 2장 · 색상표 복구본 보존하기

원본 표식은 파랑, 빨강, 파랑, 초록 순서입니다. 첫 칸을 노랑으로 바꿀 때 편집용 이름과 원본은 같은 리스트를 가리켜야 합니다. 복구용 이름에는 수정 전 표식이 남아야 합니다.

| 관찰할 순간 | 원본의 첫 칸 | 복구본의 첫 칸 | 관찰한 목록의 전체 수 / 색 종류 수 |
| --- | --- | --- | --- |
| 편집용 이름으로 첫 칸을 바꾼 뒤 | | | 원본: |
| 복구본에 빨강을 더한 뒤 | | | 복구본: |

복구본의 첫 칸에도 노랑이 들어 있다면 어느 줄에서 사본을 만들었는지 확인하세요. 사본 만드는 줄을 표식을 바꾼 뒤로 옮겼을 때 결과가 어떻게 달라지는지 시험한 뒤 다시 원래 순서로 돌리세요.

## 3장 · 측정 기록에서 양의 짝수만 남기기

음수는 취소한 기록, 0은 길이가 없는 기록입니다. 이번 검사는 남은 양수 중 짝수 길이만 추립니다. 처음 나온 순서와 반복된 기록을 유지하세요. 반복문을 먼저 작성하고 같은 입력에서 리스트 컴프리헨션을 작성합니다.

| 입력 목록 | 손으로 추린 목록 | 반복문 출력 | 컴프리헨션 출력 |
| --- | --- | --- | --- |
| [-4, 0, 6, 3, 2, 6] | | | |
| [] | | | |
| [0, 0] | | | |
| [-2, -8] | | | |

첫 목록에서는 6, 2, 6이 이 순서로 남고 나머지 목록은 모두 비어야 합니다. 두 구현에 같은 잘못된 조건을 쓰면 두 출력끼리는 같을 수 있습니다. 두 출력을 손으로 쓴 목록과도 대조하세요.

## 4장 · 새 녹음과 이어 녹음 분리하기

새 녹음에서 표식이 이전 녹음에 붙는 문제를 고칩니다. 먼저 노트북의 keep_label 예제를 실행해 두 번째 출력에 어느 표식이 섞이는지 적으세요. 이어서 add_label을 완성하고 다음 순서로 점검하세요.

| 호출 | 확인할 위치 | 예상 표식 | 실제 표식 |
| --- | --- | --- | --- |
| 목록을 생략하고 "시작" 추가 | 반환값 | | |
| 목록을 생략하고 "종료" 추가 | 반환값 | | |
| 직접 만든 빈 목록 shared에 "리허설" 추가 | 호출한 뒤의 shared | | |
| 같은 shared에 "공연" 추가 | 호출한 뒤의 shared | | |

앞의 두 줄은 각각 표식 한 개만 나와야 합니다. 마지막 호출 뒤 shared에 리허설과 공연이 순서대로 남는지도 확인하세요. 함수가 반환한 목록만 보고 넘어가면 호출자가 준 빈 목록을 실수로 바꿔치기한 오류를 놓칩니다.

## 5장 · 녹음기 두 대의 카운터 검수하기

노트북에 Counter를 완성하고, 각 행을 시작할 때 a와 b를 새로 만드세요. a.add(8)은 A에 8초를 더하고 a.reset()은 A의 합계를 0으로 되돌립니다. 각 행의 마지막 연산 뒤 A와 B의 총 초를 적으세요.

| 순서 | 입력 순서 | 예상 A, B | 실제 A, B |
| --- | --- | --- | --- |
| 첫 번째 | A에 8, B에 5, A에 2를 더한 뒤 A 초기화 | | |
| 두 번째 | B에 4를 더하고 A를 초기화한 뒤 B에 3을 더함 | | |
| 세 번째 | A에 4를 더하고 B에 0을 더한 뒤 B 초기화 | | |

세 결과는 순서대로 (0, 5), (0, 7), (4, 0)입니다. 받아야 할 값과 다르면 초기화 직전과 직후의 두 값을 따로 출력해 어느 줄에서 예상이 빗나갔는지 찾으세요.

마지막으로 새 카운터에 1분과 1초를 각각 초로 바꿔 더하세요. 필요한 예약 시간은 올림하여 2분입니다. 두 번째 녹음 길이를 0초로 바꾸면 총 60초이고 예약 시간은 1분입니다. 함수를 호출한 곳에서 반환값을 쓰는 줄에 밑줄을 그어 보세요.
