02

사용자 메시지의 role과 content

SDK는 Python에서 요청을 만들고 응답을 읽게 해 주는 라이브러리입니다. 고정 응답으로도 메시지, 출력 본문, 사용량 필드를 따로 살펴볼 수 있습니다.

SDK는 파이썬 코드에서 서비스의 요청과 응답을 다루게 해 주는 라이브러리입니다. 먼저 보내려는 내용만 조립하면 실제 통신 없이도 모델 이름과 사용자 메시지가 어느 칸에 들어 있는지 볼 수 있습니다.

API·SDK·토큰의 관계

API는 프로그램이 서비스와 요청·응답을 주고받는 규약입니다. Python SDK는 그 규약을 Python 객체와 메서드로 사용하도록 돕는 라이브러리입니다. SDK를 설치하는 것과 서버에 모델 요청을 보내는 것은 별개의 일입니다.

모델은 요청의 입력을 처리하고 출력을 생성합니다. 토큰은 모델이 텍스트 등을 처리할 때 사용하는 단위이며 한국어 글자 수와 일치하지 않습니다. 사용량 필드의 입력 토큰·출력 토큰과 답변 글자 수를 같은 값으로 취급하지 않습니다.

컨텍스트는 모델이 이번 요청에서 참고할 입력 범위입니다. 긴 문서를 넣는다고 전체 내용을 정확히 기억한다는 뜻은 아닙니다. 모델 선택에는 기능 지원, 입력 길이, 응답 품질, 지연, 비용 조건을 함께 확인해야 합니다. 이번 교재는 특정 모델을 모든 과제에 최선이라고 정하지 않습니다.

03

MockTransport를 이용한 SDK 호출

아래는 제공 셀입니다. OpenAI SDK와 HTTPX가 설치된 커널에서는 SDK의 responses.create를 실제로 호출합니다. 전송은 로컬의 MockTransport가 받아 고정 응답을 돌려주므로 계정과 모델 서버를 쓰지 않습니다.

셀 02 · 모의 SDK 응답 생성

제공 함수는 요청에서 user 역할을 확인하고, message 하나와 사용량 예시가 든 HTTP 응답을 준비합니다.

제공 함수는 네트워크 대신 예제 응답을 만듭니다. 셀 03에서는 본문을, 과제 04에서는 같은 응답의 사용량을 읽습니다. 처음에는 함수 안의 생성 코드보다 반환된 응답 한 건을 따라가세요.

이 셀은 함수를 정의합니다. 아직 요청을 보내지 않았으므로 답변 출력이 없습니다.

모의 응답 환경 구성

이 모의 실행은 SDK가 요청을 구성하고 응답을 읽는지 확인합니다. 실제 모델의 답변 품질·사용 가능 모델·계정 권한·요금·네트워크는 확인하지 않습니다.

셀 03 · output_text 읽기

고정 응답에 적힌 안내 문장을 SDK가 꺼낸 값과 대조하세요.

실행 결과

가상 안내를 확인했습니다.

SDK가 꺼낸 본문은 ‘가상 안내를 확인했습니다.’입니다. 이 문장은 제공 함수의 응답 본문에서 왔습니다. 실제 서비스 모델의 생성 결과나 품질을 보여 주지는 않습니다.

SDK 요청 함수

셀 03에서 request 앞에 붙인 별표 두 개는 셀 01에서 만든 사전을 responses.create의 이름 있는 인자로 풀어 전달합니다. 이 요청에는 model, input, max_output_tokens가 들어 있습니다. 한도를 300으로 두어도 응답의 실제 총량은 usage에서 별도로 읽습니다.

모의 전송 함수는 JSON을 담은 HTTP 응답을 반환합니다. 이를 받은 SDK가 response 객체를 만들고, response.output_text가 그 안의 텍스트를 꺼냅니다. 상태와 사용량은 각각 response.status와 response.usage에서 읽을 수 있습니다.

04

usage와 응답 완료 상태

토큰은 모델이 입력과 출력을 세는 단위입니다. 과금이나 지연을 추측하지 않고 응답에 실제 제공된 값을 읽습니다. 요청 상태가 미완료면 본문 길이만 보고 성공으로 기록하지 않습니다.
