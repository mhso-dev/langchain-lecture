# 공지로 배우는 SDK·프롬프트·챗봇 검수

2026-11-26. 8~10일은 공지를 모델에 보내고 독자·요구 조건·출력 예시를 바꾸며 두 결과를 읽는다. 11~13일은 사용자가 날짜를 정정하는 대화와 새 대화를 비교하고 같은 호출을 Streamlit에 연결한다. Git의 오타 수정 예제는 원래 diff를 그대로 출력한다.

집필 때 OpenAI SDK 3.35.1로 대표 요청 8건, 멀티턴·새 대화 4건을 실제 호출했다. 독립 검수자가 저장된 답과 원문, 학생 과제와 풀이를 대조했다. ‘미기재’와 실제 미결정을 구별하도록 보완했고, 전체 실행으로 서버가 바로 꺼지는 문제를 수정했다. Streamlit 1.67 AppTest에서는 모델만 대체해 입력 2건·2쌍, 위젯만 조작한 뒤 2건·2쌍, 초기화 후 0건·0쌍, 새 질문 후 1건·1쌍을 확인했다.

빌드 후 scripts/check.py와 scripts/check_pre_mid_notebooks.py를 실행했다. 유료 모델 실습의 자동 검사는 구문·HTML·노트북 일치를 확인하며 추가 비용을 발생시키지 않는다. 일일 과제 ZIP의 1~13일 노트북도 웹 다운로드와 대조했다. 학생 Windows/WSL 환경과 실제 수업 소요 시간은 미측정이다.
