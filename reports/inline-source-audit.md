# 학생용 교재 원문·입력 검수

2026년 11월 27일 기준으로 1~116장 HTML과 노트북, 1~5장의 두 선택 과정, 개인 과제와 공통 활동지, 117~120장의 기존 특강 과제를 확인했다. [수정한 절 열기](../dist/updates/index.html#prompt-inline).

## 검증 범위

각 구간의 별도 읽기 전용 검수자가 최초 지적과 수정 결과를 대조했다. 독자·날짜·예외 조건, 사례의 질문과 판본, 프로젝트 예시의 필드를 원자료로 다시 확인했다. Python 기초의 변형 입력은 같은 준비 데이터로 풀이했고, 챗봇 예시는 이전 대화만 달라지는지 호출 입력을 대조했다. 41개 프로젝트 노트북의 전체 코드 셀을 Python에서 세 번씩 실행했다. 내장 예시만 있는 폴더, 이전 장의 결과가 쌓이는 폴더, 사용자가 시작 JSON을 둔 폴더에서 총 123회 실행해 출력과 다음 장의 입력을 대조했다.

41개 프로젝트는 Jupyter 커널에서도 각 장을 단독으로 실행한 경우와 이전 장에 이어 실행한 경우를 각각 확인했다(82회). 두 경우 모두 저장된 출력과 다음 장으로 넘기는 데이터가 일치했다.

생성된 HTML 155개의 내부 링크와 교재·노트북 116쌍을 검사했다. 14~42장 배포 노트북과 실습 묶음도 원본과 대조했다.

한국어 최종 대조에서는 인용 부호 안의 문장이 달라진 곳을 다시 읽었다. 회원·진행자용 지시와 답은 새로 쓴 예시이고, 그대로 읽는 회의 메모와 자료 발췌는 원문과 대조했다.
