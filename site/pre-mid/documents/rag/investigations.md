# 문서 챗봇을 동료에게 넘기기까지

각 장에서 읽은 한 사례에 새로운 조건을 붙여 보세요. 먼저 자료만 읽어 기대 결과를 정한 뒤 노트북에서 실행하고, 서로 달랐던 지점과 원문 쪽을 적습니다. 답을 잘 썼는지 판단할 때 실제 응답을 그대로 옮기세요.

## 14장 · 모델에게 원문을 보내지 않은 경우

A형 1.1판 1쪽의 표시등 설명으로 채팅형 프롬프트를 만드세요. 처음에는 자료 칸에 빈 문자열을, 두 번째에는 원문을 보냅니다. 학생 두 사람이 답만 읽고 어떤 실행에서 문서를 받았는지 맞혀 봅니다. 다음에는 완성 프롬프트를 열어 실제로 들어간 값을 확인하세요. 모델이 빈 원문에서도 우연히 사실과 같은 답을 했다면 근거를 전달한 것으로 인정할 수 있을까요?

| 실제로 넣은 원문 | 모델에 전달된 마지막 메시지 | 실제 답 | 원문으로 확인한 사실 |
|---|---|---|---|
| 빈 문자열 | | | |
| A형 표시등 문단 | | | |

## 15장 · 상담 메모의 출처 복구

담당자의 메모에는 “A형은 30분, 파일은 계속 저장된다”라고만 적혀 있습니다. 2027년 4월 문의자가 이 답을 받아도 될지 검수하세요. 자료 폴더에서 원본 두 개를 열고 **구판에서도 맞는 부분**, **판본이 바뀌어 틀린 부분**, **고쳐 쓸 문장**을 쪽수와 함께 적으세요. 동료에게 파일명과 쪽수만 건네 같은 문장을 찾게 합니다.

## 16장 · 어느 분할이 실제 문의에 유리한가

대여 안내 개정판 2쪽을 두 장의 메모로 나눠 동료에게 건네세요. 첫 시도는 “위 신규 신청 마감” 앞에서, 둘째 시도는 “장비 종류까지” 앞에서 나눕니다. 동료는 한 조각만 읽고 “수령 시간만 바꿀 때 언제까지 연락하는가?”에 답합니다. 원문을 다시 붙이지 않고도 이해할 수 있게 제목 또는 앞 문장을 얼만큼 가져올지 합의하세요.

|---|---|---|---|
| 첫 시도 | | | |
| 둘째 시도 | | | |

## 17장 · 문의자가 제품명도 모를 때

“앞에 불빛이 들어오지 않도록 설정하고 싶어요”를 검색합니다. 답할 문장을 찾기 전에 검색된 A형과 B형 각각의 동작을 쓰세요. 이어 “2027년 5월 B형”을 추가해 검색합니다. **순위가 어떻게 바뀌었는지**와 **어떤 안내를 확정할 수 있게 되었는지**는 다른 칸에 씁니다. 자기 기종을 모르는 학생에게 보낼 확인 질문 한 문장을 작성하세요.

## 18장 · 다른 사람이 같은 색인을 열 수 있는가

작업 폴더, 컬렉션 이름, 문서 수, 임베딩 모델명, 질문, 상위 세 ID를 적습니다. 짝은 커널을 재시작한 뒤 같은 폴더에서 다시 열어 결과를 비교합니다. 다음에는 저장 경로만 다른 빈 폴더로 바꿉니다. 결과가 같더라도 이전 색인을 재사용했다고 판단할 수 있는지, 어느 폴더에 자료가 생겼는지 설명하세요.

## 19장 · 답을 얻은 뒤 인용을 다시 열기

B형의 표시등을 숨긴 채로 녹음 중인지 확인하는 질문에 답을 받은 뒤, 응답에 인용된 쪽과 실제로 전달된 후보를 대조합니다. 다음에는 B형 2쪽만 모델에 주고 같은 질문을 보냅니다. 실패가 생기면 모델이 받은 문장 중 무엇이 빠졌는지 표시하세요.

## 21장 · 보류를 잘 쓴 답 고르기

다음 문구는 **오류를 찾도록 만든 세 가지 가상 답변**입니다. B형 2쪽을 읽고 사실로 확인되는 구절에만 밑줄을 그으세요. 그런 다음 문의자가 지금 할 수 있는 행동을 담아 다시 씁니다.

- “무선 전송을 지원하지 않습니다.”
- “케이블로 파일을 복사할 수 있습니다. 무선 전송 지원 여부는 주어진 설명서에서 확인되지 않습니다.”
- “블루투스를 켜고 기기 이름을 선택하세요.”

다른 학생은 같은 설명서로 “컴퓨터에 어떤 폴더가 보이나요?”를 묻습니다. 보류 문구를 그대로 반복해도 되는지 실행해 확인하세요.

## 22장 · 정답 페이지 두 개가 모두 필요한 비교

“2027년 3월과 4월 사이에 A형의 파일 분할 간격이 얼마나 늘었나요?”라는 별도 질문을 추가합니다. 두 날짜의 정답을 직접 찾아 페이지 ID를 붙입니다. 정답 하나만 1위에 들어간 검색 결과와 두 쪽 모두 들어간 검색 결과를 만드세요. K=2에서 각각 Recall과 역순위를 계산하고, 15분이라는 차이를 답할 수 있는 쪽을 고르세요.
