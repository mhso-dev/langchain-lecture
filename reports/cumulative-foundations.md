## 교육 검수와 수정

읽기 전용 검수자 `/root/reviewer`가 원본을 검토해 A1에서 A2, B1에서 B2, 두 경로에서 Git, 10장에서 11장, 13장에서 RAG로 실제로 이어지는 파일이 빠져 있다고 지적했다. 경로별 파일과 새 커널에서의 읽기 셀을 넣었다. 첫 개정 뒤에는 0초만 있는 A 원장, 빈 B 게시 목록, 완성 코드 옆의 학생 작성 기회, 두 경로 파일이 함께 있는 Git 폴더, 분·초 변환 해설을 다시 검토했다.

A는 빈 목록에서 합계 0까지 진행한다. B는 게시 대상이 한 건 이상 필요한 이유와 복원 방법을 명시했다. 2~5장 두 경로에 파일을 직접 갱신하는 학생 셀과 바로 아래 접힌 코드·출력·풀이 8개를 추가했다. Git에서 A와 B가 함께 있으면 기본 선택과 바꿀 한 줄을 안내한다. 검수자가 시작본과 풀이본을 각각 새 커널로 다시 실행한 뒤 교육 개정에 `accept`를 반환했다. 실제 수강생 소요 시간은 측정하지 않았다.

## 실행·화면·전달본

- macOS에서 Python 3.12.15, ipykernel의 새 in-process 커널을 노트북마다 생성했다. A와 B는 서로 다른 임시 수업 폴더를 사용했다. 일반 로컬 TCP 커널 시작 시 소켓 권한 오류가 발생해 같은 프로세스 안에서 별도 커널로 실행했다.
- 시작본과 풀이본에서 각각 진단 6셀, A 52셀, B 44셀, 공통 Git 16셀을 실행했다. 실제 Git 저장소·worktree·로컬 bare 원격·fetch·병합을 사용했다. A·B 풀이본에는 각 16개, 진단과 Git에는 각각 3개의 직접 코딩 답을 대입했다.
- 입력 변형도 첫 장부터 Git까지 다시 실행했다. A 추가 시간을 7초에서 2초로 바꾸자 최종 합계가 154에서 149로 바뀌었다. B 우선 물건을 우산에서 장갑으로 바꾸고 두 파일이 있는 상태에서 B를 지정하자 수신한 표시가 [장갑], 기록이 장갑 한 건이었다. 앞 파일이 없는 3장 A와 4장 B도 제공 예시로 시작했다.
- 8~10장 25개 코드 셀과 11~13장 17개 코드 셀의 시작본·풀이본을 같은 순서로 실행했다. 테스트 프로세스에서만 SDK 생성·파싱 응답을 대체했다. 패키지 설치와 화면 서버 시작·종료 5셀은 실행하지 않았다. 실제 OpenAI 클라이언트로 기본 요청 한 건을 시도했으나 APIConnectionError가 발생했다. 이전 판의 모형명이 같은 실응답을 이번 개정의 실호출 증거로 사용하지 않았다.
- Streamlit 1.67.0 AppTest가 13장에서 복사한 실제 앱 코드를 읽었다. 이전 이력을 불러오면서 요청 수가 0에 머무는지, 후속 질문 한 번에 1건·대화 2쌍인지, 원문 구절을 넣었을 때 다운로드가 나타나는지 확인했다. 풀이본에서는 새 대화 버튼으로 0건·0쌍이 되는지도 검사했다. 모델 응답은 로컬 테스트 대체값이다.
- 작업트리의 공용 dist를 쓰지 않고 격리한 사본에서 `node scripts/build.mjs`와 `python3 scripts/check_pre_mid_notebooks.py`를 실행했다. 1~13장 별칭이 공유 수업을 열고, 여섯 노트북에서 소스와 dist, pre-mid.zip 안 바이트가 같음을 확인했다. HTML 코드·출력, 접힌 풀이 구조도 대조했다. 실브라우저 390px·1280px로 확인하려 했으나 이 세션의 Chrome 프로세스가 기동 직후 종료됐다. 이 기록은 뷰포트 화면 확인을 통과로 계산하지 않는다.

## 한국어 최종 검수

모드는 산문, 최소 심각도는 S1로 두고 수정한 학생용 문장을 검토했다. 10장 답안에서 ‘305호가 없으면 미정’을 ‘장소 자체가 빠진 원문’으로 바로잡아 다른 장소가 명시된 경우와 구분했다. 11장 첫 메시지와 12장 화면 복원의 관계를 본문과 맞췄다. B3에서 문자열 양쪽의 실제 별표가 보이도록 코드 서식을 적용했다. 그 뒤 의미·수치·파일명·인용과 지시 대상을 대조했다. 구조 검사에서 문자 변경률 0.4%의 저윤문 경고가 있었으며, 수치·인용·격식 불변식과 대구 검사는 통과했다. 수정한 8문장을 다시 읽고 입력, 조건, 결과와 다음 행동을 구별할 수 있음을 확인해 `corrected`로 판정했다. 공개 범위가 확정되지 않아 외부 맞춤법 서비스에는 전송하지 않았다.
