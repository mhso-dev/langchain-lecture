06

관련 개념 더 읽기

서비스와 모델, 대화를 구분하기

LLM은 입력에 이어질 응답을 생성하는 모델입니다. 대화 서비스는 모델에 파일·검색·화면 기능 등을 결합해 사용자가 이용하도록 제공합니다. 같은 서비스라도 선택한 모델이나 모드, 계정의 사용 조건에 따라 결과가 달라질 수 있습니다.

대화에서 이전 메시지는 다음 답변의 맥락이 됩니다. 네 서비스를 공정하게 비교하려면 각 서비스에서 새 대화를 시작하고 같은 자료와 같은 요청을 사용하세요. 다른 자료를 추가한 결과는 별도 실험으로 기록합니다.

파일을 첨부했다고 모든 문장이 정확히 처리되었다고 단정할 수는 없습니다. 원문에서 확인할 핵심 항목을 먼저 정해야 답변이 빠뜨린 정보와 만들어 낸 정보를 찾을 수 있습니다.

오늘은 실제 회사 회의록을 사용하지 않습니다. 실습 파일의 인물과 모임은 교육용 가상 설정입니다. 개인정보·고객 자료·실제 비밀키가 들어 있는 문서를 업로드하지 마세요. 계정 로그인은 본인이 진행하며 암호를 동료와 공유하지 않습니다.

meeting.txt를 텍스트 편집기로 먼저 읽으세요. 확정 일정, 담당자별 작업, 마감일이 없는 작업, 합의하지 않은 항목을 표시합니다. 원문을 읽기 전에 모델 응답부터 보면 잘못된 요약을 기준으로 원문을 해석하기 쉽습니다.

ChatGPT에서 첫 결과 만들기

본인 계정의 새 대화에서 사용할 수 있는 입력 방법을 확인합니다. 파일 첨부가 가능하면 meeting.txt를 올리고 공통 프롬프트를 보냅니다. 파일 입력을 사용할 수 없다면 같은 내용을 대화 입력에 붙여 넣고 비교표에 텍스트 붙여넣기라고 기록합니다. 두 방식은 조건이 다르므로 파일 처리 성능 비교로 일반화하지 않습니다.

Claude에서 같은 조건 반복하기

새 대화에 동일한 자료와 요청을 넣습니다. 첫 서비스에서 본 오류를 막기 위한 문장을 추가하면 비교 조건이 달라집니다. 공통 요청은 그대로 두고 보완 실험은 첫 결과를 저장한 뒤 따로 진행하세요.

응답의 표가 보기 좋다는 이유로 사실 확인을 생략하지 않습니다. 예를 들어 하늘의 마감일을 다른 담당자의 마감일과 같게 적었다면 문서가 자연스러워도 근거 없는 추가입니다. 누락과 추가를 구분해 기록하세요.

Gemini와 Grok에 같은 과제 적용하기

두 서비스도 각각 새 대화에서 시작합니다. 사용 가능한 파일 입력이나 텍스트 입력을 선택하고 실제 입력 방법을 기록합니다. 첨부가 막히면 파일 종류·계정 안내·오류 메시지를 확인하고, 해결되지 않으면 대체 입력으로 진행하거나 미실행으로 남깁니다.

검색 기능이 자동으로 사용되었다면 외부 검색 결과와 첨부한 회의록의 내용을 섞었는지 확인합니다. 이번 과제의 근거는 회의록입니다. 외부 검색에서 찾은 행사를 이 모임의 결정 사항으로 넣어서는 안 됩니다.

계정이나 사용 한도 때문에 실행하지 못한 서비스를 다른 사람이 쓴 것처럼 기록하지 않습니다. 동료의 응답을 참고했다면 누가 실행한 결과인지와 조건을 표시합니다. 참고 결과는 본인의 직접 실행과 나누어 비교하세요.

이번 비교는 이 자료와 이 계정 조건에서 관찰한 결과입니다. 한 번의 회의록 요약으로 서비스 전체의 지능이나 안전성을 순위 매기지 않습니다. 먼저 기준별 통과 여부를 적고, 본인의 업무에 중요한 조건을 선택 이유로 설명하세요.

결정 사항이 맞는지, 할 일이 빠짐없이 나왔는지, 없는 정보를 미정으로 남겼는지, 제시한 근거가 원문에 있는지를 각각 판단합니다. 하나의 총점만 남기면 어떤 부분이 문제였는지 알기 어렵습니다.

이 코드는 필수 조건 칸이 비었는지만 확인합니다. 답변의 정확성을 자동 채점하지 않습니다. 표의 내용과 원문 대조는 사람이 수행합니다.

오류를 짚고 보완 응답 비교하기

보완 요청에는 무엇이 잘못되었는지와 어떤 원문을 확인해야 하는지를 적습니다. 더 잘해 달라는 말만 반복하면 수정 기준이 모호합니다. 최초 요청, 최초 응답, 보완 요청, 수정 응답을 한 묶음으로 보관하세요.

모델이 사과하거나 수정했다고 말해도 다시 원문과 비교해야 합니다. 잘못된 항목을 고치면서 다른 담당자의 작업을 누락할 수 있습니다. 수정된 항목만 보지 말고 네 가지 기준을 다시 확인하세요.

응답 B를 고쳐 본 뒤, 동료가 다른 숫자나 조건 한 가지를 바꾼 응답을 만들어 서로 오류를 찾습니다. 직접 서비스 실행은 미실행으로 표시합니다. 이 과제는 원문 대조 학습을 이어가기 위한 대안이며 계정 실습을 했다는 증거가 아닙니다.
