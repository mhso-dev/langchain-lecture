가상 회고 한 행　역할 검색 입력 담당 / 문제 “장비A”가 RULE-A로 연결되지 않음 / 판단 임의로 모든 공백을 없애면 “장비AB”까지 잘못 고를 수 있음 / 변경 장비 A·B 표기만 정리 / 증거 98장 adoption-decision.json의 Q98-N01·Q98-N02 / 남은 일 처음 보는 장비명·질문을 별도로 평가. 이 행은 기록 방법의 예시이며 특정 수강생의 실제 기여를 뜻하지 않습니다.

Q98-N01, Q98-N02
공개 개발 사례의 제한된 장비명 표기. 일반 의미/실사용 품질 승인 아님.

Q98-N01과 Q98-N02에서 고친 것은 특정 장비명 표기입니다. 회고에 남길 근거는 수정 전 입력, 적용한 규칙, 수정 뒤 찾은 문서입니다. 처음 보는 표기에도 효과가 있다는 주장은 별도 문항으로, 실제 사용자가 원문을 더 잘 찾는다는 주장은 과업 관찰로 확인해야 합니다.

기여한 범위를 적을 때

고친 입력과 보존한 반례를 함께 써야 규칙이 적용되는 범위가 보입니다. Q98-N01과 Q98-N02에서 확인한 장비 표기 개선을 기록하세요. 실제 사용자가 출처를 찾을 수 있는지는 별도 과업이므로 인계할 사람과 관찰할 행동을 적습니다.

선수 개념 · 111장 최소 재현 입력과 회귀 테스트

고친 질문 ID와 새 질문에서의 성능 구분하기

Q98-N01과 Q98-N02는 표기 수정으로 고친 공개 사례의 이름입니다. 같은 기록의 independent_holdout은 not_created이므로 이 두 ID로 처음 보는 질문의 성공률을 계산할 수 없습니다. 후속 담당자가 모을 새 질문을 따로 적어 보세요.

예상 질문은 실제 평가자의 발언으로 기록하지 않습니다. 팀별 포트폴리오에는 자신이 바꾼 조건과 다른 사람이 다시 실행할 수 있는 입력을 적습니다.

팀이 마지막으로 고를 한 가지 후속 작업

남은 일을 모두 나열하지 말고 다음 결정에 영향을 주는 증거를 고르세요. 예를 들어 현장 도입을 검토한다면 공개 예시를 다시 늘리는 것보다 처음 보는 문의에서 근거 절을 찾는 행동을 관찰할 담당자·입력·기록 방식을 정합니다.

개인의 기여는 고친 입력, 바뀐 코드, 다시 얻은 출력이 연결될 때 다른 사람이 검증할 수 있습니다. 공개 질문에서 찾은 개선을 설명할 수 있어도 실제 사용자 성취와 비공개 평가가 확인됐다는 결론은 아직 낼 수 없습니다.

최종 인계물에 판본, 재현 입력, 기대 근거, 아직 확인하지 못한 항목과 확인할 역할을 함께 남기세요.
