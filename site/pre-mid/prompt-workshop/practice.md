# 공지 편집자의 프롬프트 실험 기록

원문 C1·C2·C3·C5는 노트북에 들어 있습니다. 모델에 보낸 문장과 실제로 받은 답을 기록하세요. 답의 문장이 모범 예시와 달라도 원문의 사실과 맡은 일을 제대로 전달했다면 그 근거를 쓰면 됩니다.

## 8장 · 신입 회원에게 정확한 장소 안내하기

처음 오는 회원이 공지 한 줄만 보고 찾아갈 수 있게 안내합니다. 먼저 C1으로 모델을 호출하고 날짜·시간·호수를 직접 적으세요. 다음에는 같은 지시문으로 C2를 보냅니다. 지시까지 바꾸면 장소 변경에 관한 두 결과를 비교하기 어렵습니다.

| 직접 기록할 값 | 공지 C1에 대한 응답 | 공지 C2에 대한 응답 |
|---|---|---|
| 사용한 지시문 | | |
| 실제 답 | | |
| 일시와 장소를 확인한 원문 구절 | | |
| 덧붙였거나 빠뜨린 안내 | | |

점검할 때는 C1이 201호, C2가 305호인지 봅니다. 두 원문의 모임 일시는 같습니다. 셀을 실행하지 않고 읽기만 했다면 실제 답은 빈칸으로 둡니다.

## 9장 · 회원용 문자와 진행자용 문자 만들기

C1에서 독자만 바꿔 두 문자를 작성하세요. 회원 문자를 받은 사람이 가져올 물건, 진행자 문자를 받은 사람이 도착할 시각과 준비할 물건을 적습니다. 이제 하나를 골라 어투·길이·포함할 행동 가운데 조건 하나를 수정하세요.

| 기록 | 내 문장 |
|---|---|
| 최초 지시와 실제 답 | |
| 잘 전달되지 않은 행동과 근거 | |
| 변경한 지시 한 구절 | |
| 바뀐 답에서 그 조건을 확인할 문장 | |
| 다른 공지로 다시 시험할 점 | |

진행자는 오후 3시 40분까지 도착해 책상마다 녹음기 한 대를 놓아야 합니다. 회원의 이어폰과 진행자의 녹음기가 한 사람의 준비물로 묶였다면 독자 조건을 다시 쓰세요.

## 10장 · 모임 정보 접수 양식 작성하기

예시 한 쌍을 먼저 읽으세요. 입력이 “토요일 3시, 도서관 2층에서 만나요”라면 모범 출력의 첫 줄은 “모임 일시: 토요일 3시”, 둘째 줄은 “모임 장소: 도서관 2층”입니다. 이제 다른 장소·일시로 직접 가상 입력 한 건과 출력 두 줄을 쓰고 세 줄을 내 지시문에 붙이세요. C3에 시험한 뒤 C5로 다시 보냅니다. C5에는 숫자와 날짜가 보이지만 그 날짜는 제출 기한입니다. 날짜를 찾는 데 그치지 말고 어느 사건의 날짜인지 읽어 보세요.

| 원문 | 기대한 모임 일시 / 모임 장소 | 실제 응답 | 근거가 없는 부분과 수정 지시 |
|---|---|---|---|
| C3 | | | |
| C5 | | | |
| 짝이 새로 쓴 공지 | | | |

C3에서는 5월 21일 금요일 오후 4시와 장소 미정, C5에서는 두 항목 모두 미정이어야 합니다. 세 번째 입력은 답을 미리 알려 주지 말고 서로 바꿔 시험하세요. 다음 시간에는 같은 대화에서 날짜만 정정해 보겠습니다.

## 회의 메모를 맡은 편집자의 개인 과제

[운영진 회의 메모 M1과 앞뒤 문서](../documents/sources/editing-desk.md)를 엽니다. 첫 요청에는 M1만 사용합니다. 다른 사람이 응답만 읽고 행동할 수 있게 만드는 일이 목표입니다.

1. **8장 실험**. 신청하려는 회원이 꼭 알아야 할 두 가지를 먼저 손으로 적습니다. 평범한 첫 요청을 보내고 받은 문장에서 그 두 가지를 표시합니다. 원문 한 문장만 바꾸어 다시 보냅니다. 바꾼 부분만 새 답에 반영됐는지 확인합니다.
2. **9장 편집**. 회원 안내와 진행자 준비 메모를 각각 씁니다. M1만으로 집결지를 특정할 수 있는지 판단한 뒤, 이번에는 M0도 함께 보내 보세요. 신청 기한과 예외 대상을 모두 넣고 길이를 줄이려면 어떤 지시를 고치는지 기록하세요. E1의 잘못된 구절을 찾아, 같은 오류가 있는 초안에도 쓸 수 있는 수정 지시 하나를 만듭니다.
3. **10장 접수**. 모임 시작·참가 신청 마감·집결지 세 칸을 정합니다. 예시를 한 쌍 직접 쓰고 M1, E2 순서로 시험합니다. 취소 마감을 참가 신청 마감으로 잘못 옮겼다면 두 사건의 차이를 지시문에 반영합니다.
4. **새 분야**. [시설 점검 S1](../documents/sources/facility-notices.md)만 받은 사서가 됩니다. 반납하러 오는 이용자용 문자를 씁니다. 짝에게 문자만 보여 주고 “오전 10시에 어디에서 반납할 수 있나요?”, “열람실에 갈 수 있나요?”라고 묻습니다. 대답에 필요한 구절이 없었다면 실제 문장을 한 번 고쳐 보세요.

| 저장할 증거 | 적을 내용 |
|---|---|
| 처음 보낸 것 | 원문 이름, 내 지시, 실제 응답 |
| 판정 | 잘못되거나 빠진 구절, 대조한 원문 문장 |
| 고친 것 | 바꾼 지시 한 줄과 새 응답에서 확인한 부분 |
| 새 자료 | 처음 본 자료에서 같은 지시를 쓴 결과와 처리하기 어려웠던 점 |

[편집 데스크 모범 예시와 채점 근거](../documents/answers/editor-desk.md)는 직접 원문에 표시한 뒤 여세요. 활동 중에는 위 표에서 실제 모델의 답과 자신이 손으로 다시 쓴 답을 구분하세요.
