# 녹음기 설명서에서 근거 찾기

두 기기는 이름이 비슷하지만 표시등을 다루는 방법이 다르다. A형은 4월에 설명서가 바뀌었다. 질문에 답할 때 기종과 사용 시점을 먼저 표시하고, 어느 문장이 답을 뒷받침하는지 직접 확인한다.

| 설명서 | 적용 기간 | 원문 |
| --- | --- | --- |
| 들소리 A형 1.0판 | 2027년 3월 1일~3월 31일 | [A형 1.0판 PDF](sources/recorder-a-1.0.pdf) |
| 들소리 A형 1.1판 | 2027년 4월 1일부터 | [A형 1.1판 PDF](sources/recorder-a-1.1.pdf) |
| 들소리 B형 1.0판 | 2027년 4월 1일부터 | [B형 1.0판 PDF](sources/recorder-b-1.0.pdf) |

## 3부에서 남길 검색 기록

> **D01**　2027년 5월에 쓰는 A형도 녹음할 때 앞쪽 빨간불이 안 보이게 할 수 있나요?

> **D05**　2027년 5월 기준으로 B형에서 녹음 파일을 무선으로 보내는 방법이 있나요?

[개발용 질문](questions/recorder-dev.csv)에서 D01을 읽고 먼저 직접 답한다. 세 PDF만 검색기에 넣는다. 검색 결과의 문서명과 실제 쪽수를 위에서부터 적고, 내가 찾은 쪽이 몇 번째에 나왔는지 표시한다. 같은 문구가 여러 판본에 나오면 질문의 시점에 맞는 쪽을 고른다. PDF는 표지 없이 본문 1쪽에서 시작한다.

다른 질문도 같은 순서로 풀어 본다. 검색한 쪽을 적었으면 [개발용 대조표](answers/recorder-dev.csv)를 열어 문서명과 쪽수를 맞춰 본다. D05처럼 어느 쪽에서도 답을 찾을 수 없는 질문은 순위 계산에서 따로 빼서 답변을 보류했는지 본다. 다음 수업에서 같은 검색을 다시 할 수 있도록 질문 ID, 원본 PDF 파일명, 색인 버전, 검색 순위를 노트북에 남긴다.

## 5부에서 다시 확인할 것

같은 세 파일과 같은 질문으로 그래프를 실행한다. D01에서 B형의 문단만 검색됐다면 기종이 어긋났음을 어디에서 알아차렸는지 적는다. 실제로 재검색했을 때만 첫 검색어와 바뀐 검색어, 두 후보 목록을 나란히 기록한다. 문서에 없는 기능을 묻는 질문은 마지막에 어떤 노드에서 왜 멈췄는지 확인한다.

## 6부에서 동료에게 건넬 결과

개발용 질문으로 기준선과 변경안을 비교하며 모델·문서·색인·질문을 고정한다. 바꾼 설정 하나와 실제 실험 ID를 적는다. 틀렸던 질문을 다시 넣어 이번에 나온 답과 인용 쪽수를 적는다.

설정을 고른 뒤에 [최종 확인용 질문](questions/recorder-holdout.csv)을 열어 새로 실행한다. 답과 인용을 먼저 저장한 다음 [최종 확인용 대조표](answers/recorder-holdout.csv)로 채점한다. 결과를 보고 설정을 다시 고쳤다면 이 질문을 이미 사용했다고 기록하고, 짝에게서 처음 보는 질문을 받아 마지막으로 점검한다.

두 대조표는 집필자가 설명서를 읽고 만든 참고 답안이다. `answer` 행은 제시한 판본과 쪽의 내용으로 답할 수 있다. `abstain` 행은 그 기능을 확인할 근거가 부족해 정답 문서와 쪽을 비워 두었다. CSV 파일은 모두 UTF-8이다.
