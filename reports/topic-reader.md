# 학생용 주제별 교재 개정 · 2026년 11월 26일

학사 수업표의 120개 자료를 주제별로 연결했다. 일반 학습 단원은 15개, 팀 프로젝트와 현장 활동 안내는 3개다. 각 세부 자료에서 해당 단원 본문으로 돌아갈 수 있다.

교육 검수자는 시작 코드로 전체 노트북을 실행한 뒤 과제 셀을 정답으로 교체해 다시 실행했다. 첫 검수에서 일부 정답이 시작 셀에서만 만들어지는 변수를 참조했다. 작성자는 과제 입력을 별도 준비 셀로 옮기고 각 일반 단원에 두 번째 사례와 과제를 추가했다. 재검수에서 15개 노트북의 코드 셀 91개와 접힌 풀이 31개의 결과가 저장 출력과 일치했다.

LangGraph 단원은 먼저 고정 간선이 근거 없는 답변으로 이어지는 경우를 재현한다. 상태, 일반·조건부 간선, 경로 선택, 종료와 재검색 한도를 같은 그래프에서 확인한다. 근거가 있는 질문, 검색어를 고쳐야 하는 질문, 자료에 없는 질문을 실행해 설명과 대조했다.

로컬 검증은 Python 3.12에서 수행했다. 웹과 노트북의 제목·코드·출력, 일차별 자료와의 연결, 한글 탐색 문구를 확인했다. 공개 여부가 확정되지 않아 외부 맞춤법 검사에는 원고를 전송하지 않았다. 실습 입력은 로컬 예시이며 실제 학생의 진도와 수업 시간은 아직 측정하지 않았다.
