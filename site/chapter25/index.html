03

prepare_inputs()로 질문과 문맥 조립

이 장의 준비 함수는 질문과 자료를 validate 함수로 검사한 뒤 question, context 두 칸을 만들어야 합니다. 빈 목록은 정상적인 ‘근거 없음’으로 None을 반환합니다. 출처가 망가진 자료까지 None으로 처리하지 않습니다.

문맥 생성 함수 구현

prepare_inputs는 질문과 문서 목록을 받아 LCEL 입력을 만듭니다. 질문 양끝 공백을 제거하고, 비어 있거나 문자열이 아니면 ValueError로 멈춥니다. 문서 목록도 검사한 뒤 빈 목록이면 None을 반환합니다. 정상 결과에는 question과 context 두 키만 둡니다.

셀 03에서 정의한 validate_documents를 그대로 사용하세요. page=0인 자료는 쪽 번호 검사에서 멈추고 같은 ID가 두 번 들어오면 중복 검사에서 멈춥니다. 잘못된 문서가 문맥에 들어가는 일을 이 단계에서 막습니다.

문맥은 format_context와 같은 순서와 줄바꿈을 사용합니다. 임의로 출처를 채우거나 문서 본문을 줄여 다른 근거를 만들지 않습니다. 오늘의 구현 과제는 검증·빈 근거·정상 입력의 흐름을 연결하는 것입니다.
