# 공지 편집자의 프롬프트 실험 기록

모델에 보낸 문장과 실제로 받은 답을 기록하세요. 답의 문장이 모범 예시와 달라도 원문의 사실과 맡은 일을 제대로 전달했다면 그 근거를 쓰면 됩니다.

## 8장 · 신입 회원에게 정확한 장소 안내하기

**첫 모임(C1)**

> 5월 21일 금요일 오후 4시에 가온관 201호에서 소리채집 동아리 첫 모임을 엽니다. 신입 회원은 이어폰을 챙겨 오세요. 진행자는 모임 20분 전에 도착해 녹음기를 책상마다 한 대씩 놓아 주세요.

**장소 변경(C2)**

> 5월 21일 금요일 오후 4시에 가온관 305호에서 소리채집 동아리 첫 모임을 엽니다. 신입 회원은 이어폰을 챙겨 오세요. 진행자는 모임 20분 전에 도착해 녹음기를 책상마다 한 대씩 놓아 주세요.

처음 오는 회원이 공지 한 줄만 보고 찾아갈 수 있게 안내합니다. 먼저 C1으로 모델을 호출하고 날짜·시간·호수를 직접 적으세요. 다음에는 같은 지시문으로 C2를 보냅니다. 지시까지 바꾸면 장소 변경에 관한 두 결과를 비교하기 어렵습니다.

| 직접 기록할 값 | 공지 C1에 대한 응답 | 공지 C2에 대한 응답 |
|---|---|---|
| 사용한 지시문 | | |
| 실제 답 | | |
| 일시와 장소를 확인한 원문 구절 | | |
| 덧붙였거나 빠뜨린 안내 | | |

점검할 때는 C1이 201호, C2가 305호인지 봅니다. 두 원문의 모임 일시는 같습니다. 셀을 실행하지 않고 읽기만 했다면 실제 답은 빈칸으로 둡니다.

## 9장 · 회원용 문자와 진행자용 문자 만들기

C1에서 독자만 바꿔 두 문자를 작성하세요. 회원 문자를 받은 사람이 가져올 물건, 진행자 문자를 받은 사람이 도착할 시각과 준비할 물건을 적습니다. 이제 하나를 골라 어투·길이·포함할 행동 가운데 조건 하나를 수정하세요.

| 기록 | 내 문장 |
|---|---|
| 최초 지시와 실제 답 | |
| 잘 전달되지 않은 행동과 근거 | |
| 변경한 지시 한 구절 | |
| 바뀐 답에서 그 조건을 확인할 문장 | |
| 다른 공지로 다시 시험할 점 | |

진행자는 오후 3시 40분까지 도착해 책상마다 녹음기 한 대를 놓아야 합니다. 회원의 이어폰과 진행자의 녹음기가 한 사람의 준비물로 묶였다면 독자 조건을 다시 쓰세요.

## 10장 · 모임 정보 접수 양식 작성하기

**장소 공지 전(C3)**

> 5월 21일 금요일 오후 4시에 소리채집 동아리 첫 모임을 엽니다. 신입 회원은 이어폰을 챙겨 오세요. 진행자는 모임 20분 전에 도착해 녹음기를 책상마다 한 대씩 놓아 주세요.

**짝에게 건네는 새 공지(C5)**

> 5월 28일 금요일 오전 11시까지 지난 모임에서 녹음한 소리를 동아리 게시판에 올려 주세요. 파일 제목에 녹음 장소를 넣어 주세요. 다음 주 모임에서 함께 들을 파일은 진행자가 두 개 고릅니다.

예시 한 쌍을 먼저 읽으세요. 입력이 “토요일 3시, 도서관 2층에서 만나요”라면 모범 출력의 첫 줄은 “모임 일시: 토요일 3시”, 둘째 줄은 “모임 장소: 도서관 2층”입니다. 이제 다른 장소·일시로 직접 가상 입력 한 건과 출력 두 줄을 쓰고 세 줄을 내 지시문에 붙이세요. C3에 시험한 뒤 C5로 다시 보냅니다. C5에는 숫자와 날짜가 보이지만 그 날짜는 제출 기한입니다. 날짜를 찾는 데 그치지 말고 어느 사건의 날짜인지 읽어 보세요.

| 원문 | 기대한 모임 일시 / 모임 장소 | 실제 응답 | 근거가 없는 부분과 수정 지시 |
|---|---|---|---|
| C3 | | | |
| C5 | | | |
| 짝이 새로 쓴 공지 | | | |

C3에서는 5월 21일 금요일 오후 4시와 장소 미정, C5에서는 두 항목 모두 미정이어야 합니다. 세 번째 입력은 답을 미리 알려 주지 말고 서로 바꿔 시험하세요. 다음 시간에는 같은 대화에서 날짜만 정정해 보겠습니다.

## 회의 메모를 맡은 편집자의 개인 과제

**운영진 회의 메모(M1)**

> 6월 14일 오전 10시에 녹음 산책을 시작한다. 참가 신청은 6월 12일 오후 6시까지 동아리 게시판에서 받는다. 지난 활동에서 이미 신청서를 낸 회원은 다시 신청할 필요가 없다. 집결지는 지난번과 같다. 진행자는 시작 30분 전에 도착해 이름표를 꺼내 둔다. 비가 오면 출발 여부를 당일 오전 8시 게시판에 공지한다.

**8장 · 신청 마감 바꾸기**
처음 신청하는 회원에게 신청 방법과 마감을 한 문장으로 안내하세요. 메모의 ‘오후 6시’만 ‘오후 5시’로 바꿔 다시 요청하고 두 답을 비교하세요.

**9장 · 독자별로 안내 쓰기**
같은 메모로 기존 신청자와 진행자에게 보낼 문자를 한 줄씩 쓰세요. 다음 두 자료는 집결지를 묻거나 잘못된 초안을 고칠 때 사용합니다.

**지난 산책 안내(M0)**

> 지난 녹음 산책 때는 솔빛관 1층 안내대 앞에서 모였습니다. 안내대는 정문으로 들어오면 오른쪽에 있습니다.

회의 메모만 보냈을 때와 지난 산책 안내를 함께 보냈을 때, 어느 쪽에서 건물 이름까지 확인할 수 있나요?

**수정할 초안(E1)**

> “6월 12일 오후 6시에 솔빛관에서 녹음 산책이 시작됩니다. 기존 신청자를 포함하여 전원 다시 신청해 주세요. 비가 오면 자동 취소됩니다.”

초안을 회의 메모와 대조해 신청 마감, 집결지, 재신청 조건과 우천 시 안내를 바로잡으세요.

**10장 · 접수표 채우기**

**비교할 공지(E2)**

> 7월 활동은 신청을 마감했습니다. 취소 신청은 7월 3일 정오까지 게시판에서 받습니다. 참가자 명단은 7월 4일에 게시합니다. 활동 당일에 사용할 집결지는 확정되는 대로 알려 드립니다.

모임 시작·참가 신청 마감·집결지를 세 줄로 받는 지시와 예시 한 쌍을 쓰세요. 회의 메모와 위 공지에 차례로 적용하고 취소 신청 마감을 참가 신청 마감으로 잘못 적지 않았는지 확인하세요.

**반납함 점검 공지(S1)**

> 7월 8일 오전 9시부터 정오까지 솔빛도서관 동문 무인 반납함을 점검합니다. 그동안 책을 반납할 이용자는 1층 안내 데스크를 이용해 주세요. 도서관 열람실은 정상 운영합니다. 예약 도서 수령은 이번 점검의 영향을 받지 않습니다.

오전 10시에 책을 반납할 이용자에게 문자를 한 줄로 쓰세요. 짝이 점검 대상과 대체 장소를 정확히 짚을 수 있는지 확인하세요.

| 저장할 증거 | 적을 내용 |
|---|---|
| 처음 보낸 것 | 원문 이름, 내 지시, 실제 응답 |
| 판정 | 잘못되거나 빠진 구절, 대조한 원문 문장 |
| 고친 것 | 바꾼 지시 한 줄과 새 응답에서 확인한 부분 |
| 새 자료 | 처음 본 자료에서 같은 지시를 쓴 결과와 처리하기 어려웠던 점 |

[편집 데스크 모범 예시와 채점 근거](../documents/answers/editor-desk.md)는 직접 원문에 표시한 뒤 여세요. 활동 중에는 위 표에서 실제 모델의 답과 자신이 손으로 다시 쓴 답을 구분하세요.
