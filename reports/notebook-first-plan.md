## 한 장을 고치는 방법

1. 학생이 수업 후 혼자 해내야 할 일을 한 문장으로 쓴다. 예를 들어 “스캔한 공지에서 대출 기간을 못 찾았을 때 원본 쪽과 추출문을 대조한다”라고 적으면 필요한 자료와 실패 조건이 드러난다.
2. 강사의 기존 학생용·강의자용 노트북에서 같은 기술을 쓰는 셀을 짝짓는다. 현재 노트북에서 이미 도달한 수준, 학생 대신 완성해 둔 코드, 설명에만 등장하는 기능을 기록한다. 입력 자료와 답안의 배포 가능 여부도 이때 확인한다.
3. 예제 하나를 처음부터 끝까지 완성한다. 준비 코드는 제공하고, 학습 목표에 해당하는 변환·호출·검증은 학생이 한 번 직접 쓴다. 한 조건을 바꿔 실패를 관찰한 뒤 코드를 고쳐 다시 실행한다. 과제 바로 아래에서 정답·출력·이유를 펼쳐 볼 수 있게 한다.
4. 학생용 HTML에는 같은 입력과 코드, 실제 출력, 그 출력으로 판단할 수 있는 내용을 싣는다. 설명은 본문에 펼쳐 놓는다. 모의 응답을 쓴 셀은 입력과 대역을 밝히고, 외부 API를 실제 호출한 셀은 모델과 관찰한 결과를 기록한다.
5. 새 실행 환경에서 시작본과 정답을 채운 사본을 차례로 실행한다. 독립 검수자는 새 입력으로 학생 과제를 다시 풀고 HTML의 표·영상·조작값과 대조한다. 장 사이에 넘기는 파일·키·쪽 번호가 바뀌면 받는 장에서도 확인한다.
