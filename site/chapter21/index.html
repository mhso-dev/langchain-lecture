셀 02 · 둘째 조각의 시작점

시작점을 16에서 겹칠 4만큼 앞으로 당깁니다.

첫 조각은 text[0:16]으로 인덱스 0~15를 담습니다. 끝점 16은 포함하지 않습니다. 네 글자를 겹치면 둘째 조각은 16−4=12에서 시작합니다. 인덱스 16은 처음부터 세어 열일곱 번째 글자입니다.

일입니다.

둘째 조각에는 ‘일입니다.’가 들어 있습니다. 서로 이어 붙일 때 이 네 글자가 두 번 나타날 수 있습니다. 입력 문장을 바꾸지 않고 시작 위치만 확인하면 이유를 볼 수 있습니다.

관련 개념 더 읽기

20장 문서 묶음으로 시작하기

진입 확인은 전반 대조 0.5H 중 15분입니다. 이전 파일이 없거나 개인 자료와 섞였으면 이 장의 제공 시작 파일로 돌아갑니다. 영어 PDF 추출 중간 결과는 공통 원문 대신 넣지 않습니다.

읽힌 문서를 바로 나누기 전에

문서를 나누는 작업을 청킹이라고 합니다. 청킹 전에 파싱 결과의 문단·페이지·숫자가 올바른지 확인해야 합니다. 잘못된 순서로 읽힌 표를 작은 조각으로 나누어도 원래 의미가 복구되지는 않습니다.

정리 규칙은 필요에 맞춰 최소한으로 적용합니다. 이 예제는 줄바꿈 형식을 통일하고 문서 앞뒤 공백만 제거합니다. 문장 안의 숫자·단위·공백을 무조건 지우지 않습니다. 원본과 정리본을 나누어 보관해야 어떤 변경이 있었는지 설명할 수 있습니다.

크기와 중첩을 이해하기

크기는 한 조각에 들어갈 범위이고 중첩은 앞뒤 조각이 함께 포함하는 범위입니다. 경계에서 문장이 끊기는 영향을 줄이려고 중첩을 둘 수 있지만 중복 저장과 검색 결과 중복도 늘어날 수 있습니다.

이번 코드는 Python 문자열의 문자 위치로 나눕니다. 토큰 기반 청킹이 아니므로 size=40을 모델 토큰 40개라고 읽지 않습니다. 문장 경계를 인식하지 않는 단순 기준선을 먼저 관찰합니다.

함수는 두 값을 돌려줍니다. chunks, mapping = chunk_document(doc)처럼 나눠 받습니다. chunks의 각 항목에는 id/text/source/page 네 필드만 둡니다. 원문 ID, 청크 순번, start/end와 설정은 mapping에 둡니다. 검색 결과가 가벼워져도 원문 위치를 잃지 않는 구조입니다.

청크 ID library-1:0으로 mapping을 찾으면 document_id가 library-1임을 알 수 있습니다. start/end는 줄바꿈 통일·앞뒤 공백 제거 후 문자열 위치이며 end는 포함하지 않습니다. 원본 바이트 위치나 PDF 좌표로 해석하지 않습니다.

서로 다른 크기 설정에서는 같은 청크 ID의 본문이 달라질 수 있습니다. 설정별 결과 폴더를 구분하고 위치표·원문 해시·설정을 함께 저장하세요. 22장에서 벡터를 만들 때도 어떤 청크 스냅샷을 썼는지 기록합니다.

짧은 문서에서도 경계 확인하기

크기 비교 실행은 같은 가상 원문을 size=16, overlap=4로 나눠 chunks.json과 source-map-experiment.json에 저장합니다. 두 파일은 항상 한 묶음으로 읽습니다. 이 문서들은 짧아서 실제 서비스의 최적 크기를 찾는 실험으로 사용할 수 없습니다.

한 조건씩 바꾸어 비교하기

먼저 overlap=0에서 size=16과 size=24를 비교해 크기 효과를 봅니다. 다음에는 size=16을 고정하고 overlap=0과 overlap=4를 비교합니다. 표의 첫째·셋째 행이 중첩 비교 쌍입니다.

많은 청크가 생겼다는 사실만으로 검색이 좋아진 것은 아닙니다. 문서 하나를 답변에 필요한 정보가 나뉘도록 잘랐는지, 같은 문장이 반복되는지, 질문에 필요한 단위가 함께 남아 있는지를 직접 읽어야 합니다.

누락과 중복의 차이 검사하기

test_offsets_coverage_and_separate_four_field_chunks는 청크 문자열과 정리된 원문의 슬라이스가 같은지 검사합니다. 원문 문자 위치가 적어도 한 번 포함되는지 확인하고, 청크에는 네 필드만 있으며 별도 위치표에는 원문 ID가 남는지 확인합니다. 중첩 때문에 같은 위치가 여러 번 포함되는 것은 누락과 다릅니다.

이 검사는 문장의 의미가 보존되는지 평가하지 않습니다. 모든 글자가 포함되어도 대출 조건과 기간이 다른 청크로 나뉘면 답변에 필요한 문맥을 놓칠 수 있습니다. 질문과 원문을 함께 읽어 판단하세요.
